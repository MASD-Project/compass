This page is the archetype that writes the translation unit of a row type's
JSON codec for the [[id:48CA6C74-8EF8-45B2-B6D6-CC6B508EE0D8][masd.cpp.json]]
facet. It is ORE Studio's =ores.cpp.wire-codec.codec_impl= with the two
MessagePack functions left off.

* Origin

ORE Studio's
=projects/ores.codegen/library/templates/ores.cpp.wire-codec.codec_impl.org= at commit
=bc0702ad46b8a6097ce5242ece7ba01067699f60=. The intro above states how the copy differs.

* Context

The context is the library's values and =masd_entity=: =row_qualified=,
=codec_include=, =codec_namespace= and =codec_root=.

* Template

The template source. compass's =tangle= codec writes it to
=masd_cpp_json.cpp.mustache= beside this page.
