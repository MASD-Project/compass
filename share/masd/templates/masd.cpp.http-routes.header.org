This page is the archetype that writes the header of an operation model's
routes for the [[id:FAFD18B3-BB36-40EE-8C25-DAA9B93D5529][masd.cpp.http-routes]]
facet.

* Context

The context is the library's values and =masd_operation=:

- =routes_guard=, =protocol_include=, =component_root= and
  =component_namespace=.
- =routes=: each routed request with =tool=, =summary=, =method=, =path=,
  =request= and =response=, both qualified, =response= being =void= when
  the route answers nothing.

A handler is a =std::function= rather than one interface per model, so a
service adds the routes it answers one at a time: the reads of a model can
be served before its writes are written.
