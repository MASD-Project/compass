This page is the archetype that writes the translation unit of an operation
model's message codecs for the
[[id:6BA0459B-525A-464F-954D-B0E83E83B92D][masd.cpp.protocol]] facet. It is
ORE Studio's =ores.cpp.wire-codec.protocol_codec_impl= for an operation with
the two MessagePack functions left off.

* Origin

ORE Studio's
=projects/ores.codegen/library/templates/ores.cpp.wire-codec.protocol_codec_impl.org= at commit
=bc0702ad46b8a6097ce5242ece7ba01067699f60=. The intro above states how the copy differs.

* Context

The context is the library's values and =masd_operation=:
=protocol_include=, =codec_namespace=, =codec_root= and =messages=, each
with =qualified= and =has_body=. A request with a body field also defines
=read_body_json=, which reads the body over =body_fields=, and
=body_json_schema=, the schema of that body.

The template source. compass's =tangle= codec writes it to
=masd_cpp_protocol.cpp.mustache= beside this page.
