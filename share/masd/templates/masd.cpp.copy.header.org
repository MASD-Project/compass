This page is the archetype that writes the header of a table's COPY writer
for the [[id:FD814477-B747-4261-A54B-5647EC66E22F][masd.cpp.copy]] facet.

* Context

The context is the library's values and =masd_entity=:

- =table=, =entity=, =row_type=, =io_namespace= and =copy_guard=.
- =copy.includes=: the headers of the column list, the parameters, the
  component's =copy_writer= and the row type.
- =copy_column_lines=: the column list split into string literals that fit
  the line, each with =text= and =last=; the literals concatenate.
- =copy_parameters=: the =declaration= of each key parameter.
