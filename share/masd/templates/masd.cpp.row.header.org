This page is the archetype that writes a table's row header for the
[[id:EB763415-450C-4D07-8CEA-0988D19BB0B3][masd.cpp.row]] facet, in the namespace =<product>::<component>::types=.

* Context

The context is the library's values (=cpp_license= among them, which
carries the generated-file marker) and =masd_entity=:

- =table=, =entity=, =row_type=, =brief=, =types_namespace= and
  =row_guard=, the include guard.
- =includes=: each =include= the members and enumerations need, standard
  headers first, then the headers the custom type registry gives.
- =enums=: each with =name=, =column=, =first= and its =values=, each a
  =value= with =last=.
- =members=: each with =member=, =cpp_type= and =initializer=, the value a
  member starts with, if any: zero, false, or the value of its enumeration
  the column defaults to, else the first.

The enumerations are in the row's header rather than in headers of their
own because a model renders one file per archetype, and an enumeration
belongs to one column of one table.

A row compares equal member by member, with a defaulted =operator===, so
the round-trip test of its JSON codec can require the value it read back
to be the value it wrote.
