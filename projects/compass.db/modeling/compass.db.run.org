One row per run of a scenario. A run names its scenario by =:ID:= and by the
blob IDs of the definition and the document it ran, never by a foreign key
into the corpus, so it outlives the document version it ran against.
Collection keeps any document whose hash a run names.

* Flags
:PROPERTIES:
:product:    compass
:component:  db
:schema:     activity
:profile:    activity-record
:END:

The profile =activity-record= fixes =current_state= and =retained=: the table holds test activity that exists nowhere else, so a model change that drops or retypes one of its columns needs a migration in the same pull request.

* Columns

** id
:PROPERTIES:
:type:         bigint
:primary_key:  true
:key_kind:     identity
:END:

The run's identity. =GENERATED ALWAYS AS IDENTITY=: read back, never written.

** campaign
:PROPERTIES:
:type:  bigint
:END:

The campaign the run belongs to.

** scenario_id
:PROPERTIES:
:type:  text
:END:

The scenario's =:ID:=.

** definition
:PROPERTIES:
:type:      bytea
:cpp_type:  store::types::blob_id
:END:

The blob ID of the scenario's definition, as =test.scenario.definition= holds it.

** scenario_hash
:PROPERTIES:
:type:      bytea
:cpp_type:  store::types::blob_id
:END:

The blob ID of the scenario document the run ran.

** tester
:PROPERTIES:
:type:  text
:END:

Who ran it.

** started_at
:PROPERTIES:
:type:        timestamptz
:default:     now()
:written_by:  database
:END:

When the run started. The database writes it; the row reads it back.

** finished_at
:PROPERTIES:
:type:      timestamptz
:nullable:  true
:END:

When the run finished; NULL while it runs.

** outcome
:PROPERTIES:
:type:      text
:nullable:  true
:values:    passed failed blocked
:END:

The run's outcome; NULL while it runs.

* Foreign keys

** campaign
:PROPERTIES:
:references:  activity.campaign
:END:

A campaign with runs cannot be deleted.

* C++

The generated row is =compass::db::types::run_row= of
=compass.db/types/run_row.hpp=. =:values:= on =outcome= generates =run_outcome=. Nothing reads or writes it yet:
Record test campaigns writes the table with its own SQL. The profile leaves
the COPY writer off.

* Notes

The investigation's =activity.run= model leaves =written_by= off
=started_at=. This model states it, as for every =now()= default the writer
never sets.
