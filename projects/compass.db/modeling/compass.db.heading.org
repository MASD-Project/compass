One row per heading of a document, in document order. The key is the
document's blob ID and the heading's =ord=, so the rows of one document are
written once with it and deleted with it.

* Flags
:PROPERTIES:
:product:    compass
:component:  db
:schema:     corpus
:profile:    owned-child-row
:END:

The profile =owned-child-row= fixes =read_only=, =current_state= and =insert_conflict: do_nothing=, as =content-addressed-row= does, for a row its owner's key and its =ord= identify, deleted with its owner.

* Columns

** hash
:PROPERTIES:
:type:         bytea
:cpp_type:     store::types::blob_id
:primary_key:  true
:key_kind:     content_hash
:END:

The blob ID of the document's source: the owner's key. The writer takes it as an argument, so the row type leaves it out.

** ord
:PROPERTIES:
:type:         integer
:cpp_type:     std::uint32_t
:primary_key:  true
:key_kind:     ord
:END:

The row's place among its document's rows of this table, from 0. It is the index of the row in the aggregate's vector, so the row type leaves it out.

** level
:PROPERTIES:
:type:      integer
:cpp_type:  std::uint32_t
:END:

The heading's level: 1 for =*=.

** title
:PROPERTIES:
:type:  text
:END:

The title as plain text, a link replaced by its description.

** path
:PROPERTIES:
:type:  text[]
:END:

The titles from the outermost heading down to this one.

** anchor
:PROPERTIES:
:type:  text
:END:

The heading's =:ID:= where it has one, else a slug of its path, numbered from 2 when an earlier heading took the slug. Unique in the document; the table does not enforce it.

** org_id
:PROPERTIES:
:type:      text
:nullable:  true
:END:

The heading's =:ID:=.

** todo
:PROPERTIES:
:type:      text
:nullable:  true
:END:

The heading's TODO keyword.

** priority
:PROPERTIES:
:type:      text
:nullable:  true
:END:

The heading's priority cookie.

** tags
:PROPERTIES:
:type:     text[]
:default:  '{}'
:END:

The heading's own tags.

** properties
:PROPERTIES:
:type:     jsonb
:default:  '{}'
:END:

The heading's drawer as a JSON object.

* Foreign keys

** hash
:PROPERTIES:
:references:  corpus.document
:on_delete:   cascade
:END:

The document this row belongs to. Deleting the document deletes the row.

* SQL

** Indexes

| name   | columns | unique | where              | using | opclass |
|--------+---------+--------+--------------------+-------+---------|
| org_id | org_id  | false  | org_id is not null |       |         |

* C++

The row is =compass::db::types::heading_row= of
=compass.db/types/corpus_document.hpp=, field for field: =hash= and =ord=
are left out by their key kinds.

* Notes

=path= has no default in the table, unlike =tags=: the model states it as the
table has it.
