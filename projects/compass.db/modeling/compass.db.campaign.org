One row per story tested in an environment. Runs and notes belong to a
campaign. A campaign is exported back to the story's pages, and the
export time records when.

* Flags
:PROPERTIES:
:product:    compass
:component:  db
:schema:     activity
:profile:    activity-record
:END:

The profile =activity-record= fixes =current_state= and =retained=: the table holds test activity that exists nowhere else, so a model change that drops or retypes one of its columns needs a migration in the same pull request.

* Columns

** id
:PROPERTIES:
:type:         bigint
:primary_key:  true
:key_kind:     identity
:END:

The campaign's identity. =GENERATED ALWAYS AS IDENTITY=: read back, never written.

** environment
:PROPERTIES:
:type:  text
:END:

The name of the environment tested. It is text, not a reference to =corpus.environment=, so a campaign outlives its environment.

** story_id
:PROPERTIES:
:type:  text
:END:

The =:ID:= of the story tested.

** sprint_id
:PROPERTIES:
:type:      text
:nullable:  true
:END:

The =:ID:= of the sprint the campaign belongs to.

** opened_at
:PROPERTIES:
:type:        timestamptz
:default:     now()
:written_by:  database
:END:

When the campaign was opened. The database writes it.

** exported_at
:PROPERTIES:
:type:      timestamptz
:nullable:  true
:END:

When the campaign was last exported to the story's pages; NULL until then.

* SQL

** Unique

A story has one campaign in an environment. The rule is a table constraint,
=campaign_environment_story_id_key=, which =ON CONFLICT (environment,
story_id)= relies on, not a unique index.

* C++

The generated row is =compass::db::types::campaign_row= of
=compass.db/types/campaign_row.hpp=. Nothing writes it yet: Record test
campaigns writes the table with its own =INSERT=.

* Notes

A unique index and a =UNIQUE= constraint enforce the same rule but are
different catalog objects, which the catalog comparison of the migrations
with =schema.sql= tells apart. The =** Unique= table under =* SQL= states
the constraint, so the generated table matches migration 1's.
