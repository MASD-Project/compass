#+description: Codegen entity model for corpus.placement: a path of an environment and the blob ID of the document it holds.
#+type: masd.codegen.entity

#+brief: A path of an environment and the document it holds.
#+entity_singular: placement
#+entity_plural: placements
#+created: 2026-11-22
#+updated: 2026-11-22

One row per path of an environment. A sync deletes the placements whose paths
went, updates those whose content changed and adds the new ones, all in one
transaction, so a reader sees the old placements or the new ones, never a mix.

* Flags
:PROPERTIES:
:product:    compass
:component:  db
:schema:     corpus
:profile:    environment-state
:row_type:   placement
:END:

The profile =environment-state= is not one the investigation names; this model proposes it. It fixes =current_state= and neither =read_only= nor =retained=: a sync rewrites the row, and =drop_environment= deletes it.

* Columns

** environment
:PROPERTIES:
:type:         bigint
:primary_key:  true
:key_kind:     owner
:END:

The environment that places the path: the owner's key. The writer takes it as an argument, so the row type leaves it out; see Notes.

** path
:PROPERTIES:
:type:         text
:primary_key:  true
:key_kind:     natural
:END:

The path, relative to the environment's root.

** hash
:PROPERTIES:
:type:      bytea
:cpp_type:  store::types::blob_id
:END:

The blob ID of the document at the path.

* Foreign keys

** environment
:PROPERTIES:
:references:  corpus.environment
:on_delete:   cascade
:END:

Deleting an environment deletes its placements.

** hash
:PROPERTIES:
:references:  corpus.document
:END:

A placement keeps its document: a document is deleted only by collection, which skips any document a placement names.

* Physical space

A sync stages every placement of an environment with =COPY=, so the model
switches the COPY writer on; its profile leaves it off.

| Address         | Enabled |
|-----------------+---------|
| =masd.cpp.copy= | true    |

* C++

The row is =compass::db::types::placement= of
=compass.db/types/placement_row.hpp=: =path= and =hash=. =:row_type:= keeps
#176's name. =environment= is an =owner= key: the key of the environment
that owns the row, which the COPY writer takes beside it.

* Notes

The key kinds of the investigation had no word for a key that is the owner's
and not a content hash, so the format gained =key_kind: owner=; the type's
name, which is not =placement_row=, is =:row_type:= in =* Flags=.
