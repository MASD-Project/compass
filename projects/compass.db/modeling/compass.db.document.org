#+title: compass.db.document
#+description: Codegen entity model for corpus.document: one org document of the corpus, its common metadata as columns, its keywords and properties as JSON and its source, keyed by the blob ID of the source.
#+type: masd.codegen.entity
#+component: db
#+filetags: :model:entity:database:
#+brief: One org document of the corpus.
#+entity_singular: document
#+entity_plural: documents
#+created: 2026-11-22
#+updated: 2026-11-22

One row per distinct org document, keyed by the blob ID of its source, as the
store keys its objects. Every environment that places the same bytes shares the
row. A sync stages the row with =COPY= and inserts it with =ON CONFLICT DO
NOTHING=, so nothing updates a document: a changed file is a new row.

* Flags
:PROPERTIES:
:product:    compass
:component:  db
:schema:     corpus
:profile:    content-addressed-row
:END:

The profile =content-addressed-row= fixes =read_only=, =current_state= and =insert_conflict: do_nothing=: a row is keyed by the blob ID of what it describes, is written once with =ON CONFLICT DO NOTHING= and never updated.

The document's text. The row holds a view of it, which the caller keeps alive.

* C++

The row is =compass::db::types::document_row= of
=compass.db/types/corpus_document.hpp=, field for field: =hash= and
=loaded_at= are left out, a nullable =text= is =std::optional<std::string>=
(#176 spells it =nullable=), =text[]= is =std::vector<std::string>= and
=jsonb= is the JSON text. The aggregate =corpus_document=, which holds the
hash and the vectors of child rows, stays hand-written.

* Notes

Collection deletes a document that no placement and no =activity.run= names;
that rule lives in =io/corpus.cpp=, not in the table, and the model does not
state it.
