This page is the component overview for =compass.bench=, a simple component
in the tooling layer of the
[[id:8A9A460F-8024-4890-B091-C0D02FD84218][System Model]].

* Summary

=compass.bench= is the harness every compass-ng measurement runs through. It
installs as =compass-bench= and has three stages. All list the tracked files
of a checkout with one =git ls-files -z= call and map files with
=compass::platform::filesystem::mapped_file=.

- =read= folds every byte of every regular file into a checksum, on N
  threads.
- =includes= scans every C and C++ file (=.hpp=, =.cpp=, =.h=, =.hh=, =.cc=,
  =.cxx=, =.ipp=, =.tpp=) for =#include= directives on N threads. The scanner
  is hand-written and skips comments and string, char and raw string
  literals. The stage then resolves each include through the directories of
  =compile_commands.json=, builds the include graph and computes the
  transitive fan-in of each file, on one thread. Each step is timed
  separately.
- =parse= parses every C and C++ file (the =includes= extensions) and every
  =.sql= file with tree-sitter. Each language runs on its own, on N threads
  over ranges balanced by bytes, with one parser per thread over the mapped
  bytes. Per file it records the fastest parse time over the repetitions and
  the count of =ERROR= and =MISSING= nodes, found with a tree cursor that
  skips subtrees without errors. Each tree is deleted after counting.

* Inputs

- =compass-bench read <checkout> [-j N] [--repeat R]=. =-j= defaults to all
  cores and =--repeat= to 5.
- =compass-bench includes <checkout> --compile-commands <file> --source-root
  <dir> [--isystem <dir>]... [-j N] [--repeat R]=.
  - =--source-root= is the directory the compile commands were generated
    against. It is required because the entries of a unity build all live in
    the build tree, so no prefix of the "file" entries names the source root.
  - =--isystem= adds an implicit system directory of the compiler, which
    compile commands do not list. Print them with
    =clang++ -E -x c++ -v /dev/null=.
- =compass-bench parse <checkout> [-j N] [--repeat R]=.
- A git checkout. Tracked entries that are not regular files (submodules,
  symlinks) are skipped. A tracked file that is missing on disk is kept and
  counted as an error.
- For =includes=, the compile commands of the commit the checkout holds.

* Outputs

- For =read=: a stage table of files, bytes, errors, median, min and max wall
  milliseconds over the repetitions, and MB/s (10^6 bytes) at the median. The
  checksum, the thread count, and the =git ls-files= and =lstat= setup times
  on their own lines. The top 15 extensions by bytes, with file counts.
- For =includes=: the median, min and max wall milliseconds of the scan,
  resolve, graph and closure steps. Files and bytes scanned, includes found
  by kind, and how many resolved inside the checkout, outside it (external)
  and nowhere (unresolved). Distinct edges, the setup times, and the counts
  of compile commands, directories and search contexts. Then the top 10
  unresolved names, and the top 15 files by direct and by transitive fan-in.
- For =parse=: a stage row per language (=cpp=, =sql=) with the columns of
  =read=, then the thread count and setup times. Per language, the files
  with parse errors, the total error nodes, and the top 10 files by error
  nodes and by parse time.
- A =FAILED= line and exit status 1 when the stage read or scanned no files
  or hit any error. For =parse= this holds per language: a language with no
  files, or a file that cannot be read, fails the run. Parse errors inside a
  tree are data, not failure. A usage error exits with status 2.

* Resolution

Each compile command contributes its =-iquote=, =-I= and =-isystem=
directories. A directory under the build directory of the command stays
absolute and is external, so generated headers resolve as external while the
build tree exists. Any other directory under the source root is rebased onto
the checkout. Directories outside the source root stay absolute and are
external.

A command is anchored at the checkout directory it compiles. That is the
directory of its file or, for a unity source in the build tree, the
build-tree directory above =CMakeFiles=. Each file is searched with the
union of the commands anchored at or below its nearest ancestor that has any.
A source file therefore gets the directories of its own target, and a header
gets those of every target in its component. A file in no compiled component
gets the union of all commands.

A quoted include tries the directory of the includer, then the =-iquote=,
=-I=, =-isystem= and implicit directories. An angle include starts at =-I=.
In an internal directory, a hit must be a file of the file table. In an
external directory, a hit must be a regular file on disk.

The rule for headers is an approximation. A compiler searches a header with
the directories of the translation unit that includes it. A header whose
includes depend on the directories of its includer, such as a shared test
fixture, can be unresolved here although it compiles. Conditional
compilation is not evaluated, so an include under =#ifdef _WIN32= counts on
Linux.

* Data shape

| Type              | Holds                                                                          |
|-------------------+--------------------------------------------------------------------------------|
| =file_table=      | Columns of path, size and extension id; extensions interned once.              |
| =file_range=      | A contiguous run of file ids for one thread, balanced by bytes.                |
| =stage_result=    | Files, bytes, errors, checksum, first error and one wall time per repetition.  |
| =compile_command= | One compile_commands.json entry: directory, absolute file, argument words.     |
| =search_paths=    | Interned include directories, search contexts, and the context of each file.   |
| =include_table=   | Columns of includer, line, kind, header name and target per =#include=.        |
| =include_graph=   | Compressed sparse rows of distinct include edges over file ids.                |
| =includes_result= | The include table, the graph, the fan-in columns and wall times per step.      |
| =language_result= | A =stage_result= and columns of file id, parse ms and error nodes per file.    |
| =parse_result=    | One =language_result= per =language= (=cpp=, =sql=).                           |

* Dependencies

- =compass.platform= for =mapped_file=.
- tree-sitter from vcpkg, and the =tree-sitter-cpp= 0.23.4 and
  =tree-sitter-sql= 0.3.13 grammars from the overlay ports in
  =build/cmake/overlays/common=. The ports compile the generated parsers
  their releases ship.
- The C++23 standard library, POSIX (=posix_spawnp=, =lstat=, =stat=) and
  =git= on the =PATH=.
- Catch2, for the tests only.
