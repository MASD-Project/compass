This page is the component overview for =compass.env=, a simple component in
the domain layer of the
[[id:8A9A460F-8024-4890-B091-C0D02FD84218][System Model]].

* Summary

=compass.env= writes and versions a project's environment file, such as ORE
Studio's =.env=: a file every checkout generates, never commits, and keeps
its secrets in. The project states the file in a check document under
=compass/checks/= whose =* Definition= names the =env_format= codec; its
tables are the file's settings, inputs, versions, variables and comments.
The component holds no project's names: everything ORE Studio's
=env_init.py= wrote as a template is data in that document.

=ops::read_format= reads the tables into an =env_format= and refuses one
that does not read: a kind it does not know, versions that do not rise, a
template naming an input the Inputs table lacks or a variable of a later
row, a section or comment the Comments table lacks. =ops::check_format=
holds the versions to the variables. =ops::generate= writes the file from
the format, the inputs, the existing file, the process environment and the
service registry; =ops::status_of= says how an existing file stands;
=ops::append_version= records a version in the check document.

A variable's kind says how its value is made:

| Kind          | Value                                                                                   |
|---------------+-----------------------------------------------------------------------------------------|
| =value=       | Its argument, a template.                                                               |
| =offset=      | The sum of the whole numbers its argument's terms expand to, as base port plus offset. |
| =secret=      | The existing file's value, else a new alphanumeric secret of the argument's length, 32 by default. |
| =kept=        | The existing file's value, else the argument.                                           |
| =inherited=   | The existing file's value, else the process environment's, else the argument.           |
| =environment= | The process environment's value, else the argument; never the file's.                   |
| =version=     | The highest version; the row of the =version_variable= setting.                         |
| =file=        | A file's lines, each followed by the two characters =\n=, in double quotes.             |
| =carried=     | Every variable of the existing file whose name matches the argument, a regular expression, in name order. |

A template replaces ={name}= with an input or the value of an earlier
variable, ={name:-default}= with the default when the value is empty, and
={service.<field>}= with a field of a service; ={{= and =}}= are braces. A
name holding ={service.<field>}= is a per-service variable: a run of them is
written service by service, in the registry's order, for each entry that has
every field the row uses, and the =services= column narrows a row to the
entries it names or, with =!=, away from them. A row's =section= block is
written before it when the row before had another section, its =comment=
block before it every time. The inputs =checkout=, =home= and =now= are
compass's own; every input the Inputs table declares must be given, and no
other.

A row's =when= is a condition, and a row whose condition fails is not
written, nor are its blocks:

| =when=                     | Holds when                                   |
|----------------------------+----------------------------------------------|
| =<template>=               | the template expands to something.           |
| =<template> = <template>=  | the two sides expand to the same text.       |
| =<template> != <template>= | the two sides expand to different text.      |

The operator has a blank on each side; the first one outside braces splits
the condition, and the blanks around each side are dropped, so ={FLAG} != 0=
and ={A} = {B}= compare while ={A}=1= is a plain template. A condition's
names follow the rules of any template, and may also name the row's own
variable, which then reads the value the row would write. A row whose
condition fails leaves its name's value as another row of it wrote it, or
empty for later templates. A variable may therefore have several rows with
exclusive conditions, such as ={FLAG} != 0= and ={FLAG} = 0=: the one that
holds is written, in the place of its row.

The versions are the Versions table: a row per version, with the variables
it adds and removes, or marked format only when it changes only values,
layout or the services the registry expands. A variable's row names the
version that added it and any that removed it, and a removed row is no
longer written. The =env_format= codec reports:

- =unknown_version=: a variable that names no version, or one the table
  lacks;
- =undeclared=: a variable whose version, after the baseline, does not list
  it, which is what a new row with an old version is;
- =unknown_variable=: a version that lists a variable no row is added or
  removed in;
- =empty_version=: a version after the baseline that names no variable and
  is not format only;
- =unreadable=: a document, table, column, setting, kind or template that
  does not read;
- =duplicate_variable=: two live rows of one variable, one or both without
  a =when=, that some service could both be given; the row without a
  =when= is always written, so the file would hold the variable twice.

The environment file itself is never committed and is written only from the
table, so no committed text can show a variable written into it without a
row: the check holds the table, and =compass env status= holds each
environment's file against the table and the registry. A file is stale when
its version is older than the table's, when it lacks a variable a row
without =when= gives it (a new service in the registry adds such
variables without a new row), or when it holds a removed or undeclared one.

* Inputs

- The data tables of the check document that names =env_format=, which
  =compass.cli= compiles into the codec's =data= option and hands to
  =compass env=.
- For generation: the inputs, the overrides, the existing file, the process
  environment, the files a =file= row names, the service registry's text
  and a maker of secrets.

* Outputs

- The text of the environment file and the names it holds, in order.
- A status: the file's version, the current one, and the variables missing,
  removed and undeclared.
- The check document with a new version appended; a touched row keeps the
  table's alignment when it fits, and the table is aligned again when it
  does not.
- The =env_format= codec's findings, at the rows of the check document.

* Dependencies

- =compass.codec= for the data tables and the codec runtime.
- =compass.platform= for regular expressions; =compass.cli= gives it the
  secure random generator of =compass.platform= as its maker of secrets.
- =compass.ingest= and =compass.model=, privately, to read the service
  registry: the parser and the outline the model's loader reads it with.
- Catch2, for the tests only.
