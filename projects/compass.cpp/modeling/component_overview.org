This page is the component overview for =compass.cpp=, a simple component in
the domain layer of the
[[id:8A9A460F-8024-4890-B091-C0D02FD84218][System Model]].

* Summary

=compass.cpp= runs ORE Studio's C++ gates as codecs. Each gate was a Python
script that read the whole tree on every run; here each is a corpus codec
that reads the files of the checkout through its view, so the runtime
records every file it read and a run in which none of them changed reuses
the findings without reading anything. The gates that read every C++ file
(=portable_stop=, =enum_attributes=, =unique_type_names=,
=unity_collisions=, =exported_types=, =forward_declarable_includes=,
=stream_coverage= and =handler_registrars=) are scans: each file is mapped
to a fact once per content ID and a run after an edit maps only the edited
file, then reduces the stored facts with it. =stream_coverage= keeps the
text of a file that names a stream call, a subject or a string constant,
and of any other file only the names it calls, so it reads the rest only
as callers of a function whose parameter names a service.

The scanners are ports, not parsers. Each reproduces the rules of one
script, including what the script gets wrong, because the acceptance of the
port is the same verdict on the same commit. The first three work on bytes
with hand-written scanners: a byte of 0x80 or more counts as a word
character, as Python counts the letters of a multi-byte character, and the
non-ASCII spaces Python's =\s= also matches are not spaces. The later ones
take the scripts' regular expressions verbatim through
=compass.platform='s =text::regex=, which has Python's syntax and Unicode
classes, and read a file as Python's =read_text()= does, with its decoding
errors and line ends (=text::decoding=). tree-sitter is not used: it was
measured too slow for the always-on path (see
[[id:E2DCD7CE-4CFC-47D8-A65D-E05A4CA48EB6][Measure tree-sitter parsing]]).

A script that kept a baseline of excused findings is ported without it
where the baseline is line- or file-shaped: each entry becomes an inline
exception on the line it excused (=forward_declarable_includes=,
=core_link_edges=). A table that is the gate's configuration rather than a
list of excuses becomes an option with ORE Studio's values as its default
(=translation_unit_budget=, =xml_family_census=).

Every codec is off by default; a repository enables the ones whose rules it
keeps in its =.compass.org=.

* Inputs

- The files of the checkout, through =types::corpus_view=: =list_files=
  for the paths each gate walks and =read_file= for the bytes. No codec
  reads a document.

* Outputs

- *=exported_types=.* ORE Studio's =exported-types= gate
  (=build/scripts/check_exported_types_are_compiled.py=). A library is the
  directory two levels above a
  =projects/<component>/<part>/include/<name>/export.hpp= that defines an
  =ORES_..._EXPORT= macro as =BOOST_SYMBOL...= at the start of a line and has
  an =#ifdef ORES_..._LIBRARY= guard, and that has a =src/= directory. Its
  translation units are the =.cpp= files under =src/=. A file reaches every
  file its =#include "..."= lines name, comments included, resolved first
  against the file's own directory and then against every
  =projects/<component>/<part>/include= in pathlib order; =..= goes up only
  from a directory that exists, as the operating system resolves it. Rule
  =uncompiled_exported_type=: a header under the library's =include/=, not
  marked =AUTO-GENERATED FILE=, declares =class MACRO name= or =struct MACRO
  name= at the start of a line, and no translation unit reaches it. One
  finding per header, at its first such declaration. The codec depends on
  the listing of every path of the checkout, because an include may resolve
  anywhere.
- *=enum_attributes=.* ORE Studio's =enum-attributes= gate
  (=build/scripts/check_enum_export_attributes.py=). It reads every =.hpp=,
  =.h=, =.cpp=, =.ipp= and =.cc= file under =projects/= with its comments and
  literals blanked (=ops::erase_comments_and_literals=). A visibility macro is
  =BOOST_SYMBOL_EXPORT=, =BOOST_SYMBOL_IMPORT=, or a macro one of those files
  =#define=s with a body holding one of them, =__declspec(dllimport)=,
  =__declspec(dllexport)= or =__attribute__((visibility=. Rule
  =visibility_macro_on_enum=: an enum declaration, =enum=, an optional
  =class= or =struct=, a visibility macro, a name and =:=, ={= or =;=, not
  after =using=. One finding per declaration, at its keyword.
- *=test_case_reachability=.* ORE Studio's =reachability= gate
  (=projects/ores.codegen/scripts/check_test_case_reachability.py=). It
  is a scan whose fact is the number of cases a test source declares. It
  reads every test source under =projects/=: a file with a C++ source or
  fragment suffix (=.cpp=, =.cc=, =.cxx=, =.c++=, =.hpp=, =.h=, =.hxx=,
  =.ipp=, =.inc=, in any case) under a =tests= directory or whose stem ends
  in =_tests=, outside any =node_modules=, =venv=, =.venv=, =build= or
  =external= directory (=ops::is_test_source=). =ops::scan_source= removes
  the backslash-newline splices, blanks comments and string, raw string and
  character literals (a quote after a digit separates digits), and reads the
  logical lines: =#if=, =#ifdef= and =#ifndef= open a block, =#endif= closes
  one, and a Catch2 test macro, or a name the file's own =#define= binds to
  one, followed by =(= declares a case. Rule =case_in_conditional=: a case
  declared inside a block, once per line and block, naming the directive
  that opened the innermost block. Rule =unbalanced_conditional=: an
  =#endif= that closes nothing, or a block still open at the end of the
  file. Rule =raw_string_moves=: a raw string begins or ends elsewhere once
  the splices are removed; the file's cases are left out. Rule
  =no_test_case=: no test source, or no case in any readable one, reported
  on =projects=.

- *=unity_collisions=.* ORE Studio's =unity-collisions= gate
  (=build/scripts/check_unity_collisions.py=). Rule =unrecorded_collision=:
  two =.cpp= files under =projects/ores.*= with the same nearest
  =CMakeLists.txt= define the same name with internal linkage in the same
  named namespace, and =cmake/unity_exclusions.cmake=, a build input that
  stays, keeps at most one of them out of the unity build. Rule
  =missing_recorded_file=: the exclusions name a file that does not exist.
- *=portable_stop=.* =portable-stop=
  (=projects/ores.codegen/scripts/check_portable_stop_types.py=). Rule
  =stop_type_outside_platform=: a line outside =ores.platform= names
  =std::jthread=, =stop_token=, =stop_source= or =stop_callback=, or
  includes =<stop_token>=, comments and strings aside.
- *=unique_type_names=.* =unique-type-names=
  (=build/scripts/check_unique_type_names.py=). Rule =type_defined_twice=:
  two headers that can meet in one binary define the same qualified class or
  struct.
- *=forward_declarable_includes=.* =forward-declarable-includes=
  (=build/scripts/check_forward_declarable_includes.py=). Rule
  =includes_definition_it_only_names=: a header includes the defining
  header of a type of the =list= option only to name it. Rule
  =bad_type_list=: the list is malformed or empty. The script's baseline
  is replaced by inline exceptions.
- *=handler_registrars=, =event_registrars=, =history_registrars=.* The
  three registrar composition gates
  (=check_handler_registrar_composition.py=,
  =check_event_registrar_composition.py=,
  =check_history_registrar_composition.py=): every generated registrar of
  the named components is called from its composition file, or, for a
  handler registrar, its subjects are answered by hand.
- *=shell_command_units=, =shell_menus=, =shell_command_composition=.* The
  shell gates (=check_shell_command_units.py=,
  =check_shell_menu_collisions.py=, =check_shell_command_composition.py=):
  a menu is built once, by one file, from its name alone; a unit is
  registered once; every generated command unit is registered.
- *=route_auth=.* =route-auth= (=check_route_auth_declarations.py=). Rule
  =route_without_auth=: an =add_route= of =ores.http= whose builder chain,
  followed through =auto= locals, states no authentication position. Rule
  =too_few_routes=: fewer than 20 routes found.
- *=bff_list_requests=.* =bff-list-requests=
  (=check_bff_list_requests.py=). A hand-written BFF list request states
  what the C++ protocol decodes (=missing_member=, =filter_mismatch=,
  =wrong_rows=), and the generated =list_requests.ts= is the table the
  protocol headers give (=stale_table=). The script's generator runs
  prettier; the codec lays out each array as prettier does at the width
  =.prettierrc.yaml= sets, which reproduces the committed table.
- *=translation_unit_budget=.* =translation-unit-budget=. Rule
  =over_budget=: a unit that includes =conventions_family_pack.hpp= names
  more convention families than one or its recorded ceiling. Rule
  =below_ceiling=: a ceiling above what its unit names. The ceilings are an
  option, since each holds a number an exception cannot.
- *=xml_family_census=.* =xml-family-census=
  (=check_xml_family_coverage.py=). The =families= option is the census;
  the rules report a corpus root it does not classify, a family no document
  has, a state the generated tables contradict and a suite that names an
  unused family.
- *=stream_coverage=.* =stream-coverage=
  (=build/scripts/check_stream_coverage.py=). It reads the stream and
  durable consumer declarations of the tree (=ensure_stream=,
  =serve_step_commands=, =js_queue_subscribe=), resolving names through
  constants, =nats_subject= members, arrays and the arguments callers pass,
  and applies NATS's two rules: every durable subject has exactly one
  stream, and no two streams overlap. A declaration it cannot read is a
  finding, not a skip.
- *=core_link_edges=.* =core-link-edges= (=check_core_link_edges.py=). Rule
  =forbidden_edge=: a core's =target_link_libraries= names another
  component's core or service library. The JSON baseline is replaced by
  inline exceptions above the CMake lines.

=codecs= is a local facet, as in =compass.codec=: one descriptor each.

* Dependencies

- =compass.codec= for the descriptor, the corpus view the codecs read
  through and the diagnostic table they fill.
- =compass.platform= for regular expressions and Python's decoding.
- The C++23 standard library.
- =compass.store= and Catch2, for the tests only.
