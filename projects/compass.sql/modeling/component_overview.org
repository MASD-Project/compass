This page is the component overview for =compass.sql=, a simple component in
the domain layer of the
[[id:8A9A460F-8024-4890-B091-C0D02FD84218][System Model]].

* Summary

=compass.sql= runs ORE Studio's =sql-hygiene= gate
(=projects/ores.sql/utility/check_sql_hygiene.py=) as a corpus codec. The
script reread every SQL file of the tree on each run; the codec reads them
through its view, so a run in which no SQL file changed reuses its findings
without reading any.

The scanner is a port, not a parser: it reproduces the script's rules,
including what they get wrong, such as reporting =create  table  if not
exists= with two spaces before =if=, because the acceptance of the port is
the same verdict on the same commit. It works on bytes: a byte of 0x80 or
more counts as a word character, and the non-ASCII spaces Python's =\s=
matches are not spaces. tree-sitter is not used: its SQL grammar does not
read psql scripts (see
[[id:E2DCD7CE-4CFC-47D8-A65D-E05A4CA48EB6][Measure tree-sitter parsing]]).

The codec is off by default.

* Inputs

- The =.sql= files under each directory of the option =roots=,
  comma-separated, default =projects/ores.sql=, through =list_files= and
  =read_file= of the corpus view.

* Outputs

- *=sql_hygiene=.* One finding per defect, under four rules.
  - =unterminated_block_comment=: a block comment is still open at the end
    of the file. Block comments nest, as in PostgreSQL; =--= comments,
    dollar-quoted bodies and both quote styles hide the markers. The finding
    is at the outermost comment still open.
  - =duplicate_index=: =create [unique] index if not exists= appears more
    than once with the same name, table and columns, compared lower-cased
    with the columns' spaces collapsed. The finding is at the first.
  - =comment_splits_literals=: a comment stands between two string literals,
    which PostgreSQL joins only across whitespace; dollar-quoted bodies are
    scanned too. The finding is at the comment.
  - =not_re_runnable=: in the text with comments, literals and bodies
    masked (=ops::mask_non_code=), =create table=, =sequence=, =extension=,
    =schema= or =materialized view= without =if not exists=; =create
    trigger=, =rule=, =view=, =function= or =procedure= without =or
    replace=; =create index= without =if not exists=; =create policy= with
    no =drop policy if exists= of the same name and table in the file; and
    =create type= or =domain= with no =drop ... if exists= of the same name.
  A message holds no count: the script's depth of an open comment and the
  number of times an index is created are left out.
