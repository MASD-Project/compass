#+title: compass.serve.campaign_writes
#+description: Codegen operation model for the document service's test campaign writes: start a run, record a step, finish the run, attach a screenshot, add a note and address it.
#+type: masd.codegen.operation
#+component: serve
#+namespace: compass::db::types
#+entity_singular: campaign_writes
#+brief: The document service's test campaign writes.
#+filetags: :model:operation:serve:
#+created: 2026-11-23
#+updated: 2026-11-23

How a tester records a test campaign over HTTP. Every write names its tester,
which the gateway sends as the caller's name and which no client sets in the
body; a write without one is refused. Each runs in one transaction and is
refused, with nothing written, when it is invalid, names a row that does not
exist or conflicts with the row's state.

* Notes

- Every message but =add_note_response= matches its struct in
  =compass.db/types/campaign.hpp= in name, member names, types, optionality
  and default. =step_outcome= and =run_outcome= are the enumerations
  =:values:= names. =query::add_note= answers a bare =std::int64_t=;
  =add_note_response= wraps it so the answer is a JSON object.
- =step_result_request=, =finish_run_request= and =address_note_request=
  answer nothing: 204 over HTTP.
- The design's paths for the step, the note and the address put the
  environment first, =/v1/{env}/runs/{id}/steps/{ord}=. These requests carry
  no environment, because a run, a campaign and a note each belong to one
  environment already, so their paths start at the row they write. Finishing
  a run is a write the design's table does not list.
- =note_kinds= of =types/campaign.hpp= is not a message: it is the project's
  configuration, which =query::add_note= takes beside the request.
- Each write has a tool, as every route has in ORE Studio's catalogue. The
  design's MCP list names none of them; whether =/mcp= lists them is the
  server's choice, not the model's.
- =bytes= is binary. JSON has no binary type, so the codec must carry it as
  base64 or the route must take the file as the body.
