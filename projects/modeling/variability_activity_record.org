This page is a profile of the =masd.codegen.entity= models of compass. A
model binds it with =:profile: activity-record= in its =* Flags= drawer.

* Purpose

A test run, a step's result, a note or a screenshot: activity that a sync
cannot recreate, because nothing but the database holds it until it is
exported. The profile marks the table =retained=. =schema.sql= says so
above the table, and the catalog test of the component's migrations names
a retained table that loses or retypes a column with no migration to do it.
The key is the model's own: most activity tables have an identity key, but
a step's result is keyed by its run and step and a screenshot by its blob
ID.

* Reference entity

=compass.db.run=, one run of a test scenario.

* Assignments
