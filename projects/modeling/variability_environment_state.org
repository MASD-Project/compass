This page is a profile of the =masd.codegen.entity= models of compass. A
model binds it with =:profile: environment-state= in its =* Flags= drawer.

* Purpose

An environment and the paths it places: state a sync writes with its own
upserts and deletes, so it is not retained, and a model whose rows are
staged in bulk switches its COPY writer on itself.

* Reference entity

=compass.db.environment=, one worktree, branch or release.

* Assignments

The profile assigns no feature.
