This page is the component overview for =compass.crosscheck=, a simple
component in the domain layer of the
[[id:8A9A460F-8024-4890-B091-C0D02FD84218][System Model]].

* Summary

=compass.crosscheck= runs the ORE Studio gates that read more than one kind
of artefact: a model and the C++ headers its pasted code names, a model and
the SQL that creates its table, the generated output and the model it came
from. Each gate was a Python script that read the tree on every run; here
each is a corpus codec that reads the files of the checkout through its
view, so a run in which none of them changed reuses the findings.

The ports follow their scripts rule for rule, including the regular
expressions and the order of their tests, because the acceptance of a port
is the same verdict on the same commit. A script that reads an org model as
text with a regular expression is ported as one: the pattern decides what it
matches, and the parsed document would decide differently on an indented or
upper-case block. The text helpers of =compass.cpp= (Python's lines,
spaces, pathlib order and the finding on a byte of a file) are shared, and
the patterns go through the Python-compatible regular expressions of
=compass.platform=.

A script's baseline of known violations is not ported. Each finding it
excused is a finding here, and the tree excuses it with an inline
exception where it stands.

* Inputs

- The files of the checkout, through =types::corpus_view=: =list_files=
  for the paths each gate walks and =read_file= for the bytes.

* Outputs

- *=paste_blocks=.* ORE Studio's =paste-blocks= gate
  (=projects/ores.codegen/scripts/check_paste_block_symbols.py=). It reads
  each cpp source block of an org file under
  =projects/<component>/modeling/=, at any depth, whose header line holds
  =:implements=, from a =#+begin_src= at the start of a line to the next
  =#+end_src= there. Every header with an =include= directory on its path
  gives the (scope, identifier) pairs it mentions, its comments and literals
  blanked: a =namespace= or a =class=, =struct=, =union= or =enum= opens a
  scope at its brace, an export macro before the name is skipped, any other
  brace keeps the scope it is in. Rule =unresolved_name=: a name of a block
  rooted at =ores= whose scope holds no such identifier. Rule
  =nothing_read=: no block, no header, or no name in any block.
- *=subject_conformance=.* =subject-conformance=
  (=check_subject_conformance.py=). Rule =outside_protocol=: a =:subject:=
  line of an org file directly under =projects/<component>/modeling/=, or a
  subject written at one of the script's two sites, that is not
  =component.v1.resource.verb= with a verb of the closed set or
  =list_by_...=, =component.v1.ops.operation= or
  =component.v1.events.collection.action=. The C++ site's pattern ends at
  a single quote, as the script's does, so it reads almost nothing. Rule
  =no_declaration=: no model declares a subject. Rule =unreadable_model=: a
  model that is not UTF-8, which the script fails on.
- *=entity_writes=.* =entity-writes= (=check_entity_table_writes.py=). Rule
  =sql_writer=: a function under =projects/ores.sql/create/= whose body
  inserts into, updates or deletes from an =ores_..._tbl= table, but the
  purge. Rule =cpp_writer=: a hand-written C++ file that writes such a table
  and is not the repository of every table it writes. The 136 writers of
  the script's baseline are findings, one per function or file.
- *=money_decimal_columns=.* =money-decimal-columns=
  (=build/scripts/check_money_decimal_columns.py=). The columns of every
  org file directly under a =modeling/= directory, at any depth: a =**=
  heading, or a =:column:= key outside one, with its first =:type:= and
  =:cpp_type:=. A name is continuous when one of its tokens is a continuous
  word, money when its head noun is a money word. Rule =money_not_exact=:
  money typed a binary float or text, or =numeric= over a C++ float. Rule
  =continuous_exact=: a continuous quantity typed =numeric= or =decimal=.
  Rule =too_few_columns=: fewer than =min_columns= read. The script's two
  hand-written column lists are the options =excluded_columns= and
  =continuous_columns=, and its two baselines (7 money columns, no
  continuous one) are findings on the column's line.
- *=model_sql_types=.* =model-sql-types= (=check_model_sql_types.py=). Rule
  =type_mismatch=: a column of a model's =* Columns= section whose =:type:=
  differs, in case and spacing aside, from the type the first =CREATE
  TABLE= of its table's =_create.sql= gives it, constraints dropped. Rule
  =too_few_compared=: fewer than =min_compared= columns compared.
- *=entity_binary_types=.* =entity-binary-types=
  (=check_entity_binary_types.py=). A generated =repository/*_entity.hpp=
  binds each column with =bind= or =key= in the format its member's C++
  type travels in; rule =wire_mismatch= reports one that differs from the
  format of the column's SQL type, or a binding to a column or member that
  does not exist, =unclassified= a type the check cannot place, =no_table=
  a row whose table no create script creates, and =too_few_compared= a run
  that compared fewer than =min_compared=.
- *=generated_column_refs=.* =generated-column-refs=
  (=check_generated_column_refs.py=). Rule =not_a_member=: a generated
  =*_table.cpp= writer streams a name its entity's header does not hold.
  Rule =not_a_column=: a generated create script indexes a column or a
  table it does not create.
- *=open_reads=.* =open-reads= (=check_open_reads.py=). Rule =open_read=: a
  read of a generated handler, a =list_= or =get_= method or one that
  decodes a protocol request, that checks no permission and whose subject
  the =allow_list= page does not name. Rules =unguarded_history= (a
  history registration with no literal read code), =stale_allow= (an
  allowed subject no protocol header defines) and =no_allow_list=.

Where a script reads a file with a strict UTF-8 decode and would stop on a
file that is not UTF-8, these codecs read it with invalid bytes replaced,
except =subject_conformance=, which reports such a model.

* Entry points

| Path                                                   | Role                                                    |
|--------------------------------------------------------+---------------------------------------------------------|
| =include/compass.crosscheck/codecs/catalogue.hpp=      | The codecs this component ships.                        |
| =include/compass.crosscheck/codecs/<gate>.hpp=         | One header for each codec, named after it.              |
| =include/compass.crosscheck/ops/words.hpp=             | Python's lower, split and run of spaces over bytes.     |
| =tests/test_checkout.hpp=                              | Runs one codec over a checkout of files held in memory. |

| Target                     | Kind                                      |
|----------------------------+-------------------------------------------|
| =compass.crosscheck.lib=   | Library.                                  |
| =compass.crosscheck.tests= | Catch2 executable, registered with CTest. |

* Dependencies

- =compass.codec= for the descriptor, the corpus view the codecs read
  through and the diagnostic table they fill.
- =compass.cpp= for its text helpers and its blanking of C++ comments and
  literals.
- =compass.platform= for regular expressions and Python's decoding.
- The C++23 standard library.
- =compass.store= and Catch2, for the tests only.
