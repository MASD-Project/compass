* Question

How do I check the documents of a checkout against their contracts?

* Answer

Run =compass check=. It prints one line per diagnostic, sorted by path and
position, then a count:

#+begin_src sh :results verbatim
build/output/linux-clang-release/publish/bin/compass check
#+end_src

: doc/agile/agile.org:6:9: required_sections/missing_section: knowledge document has no "Detail" section (fix: Add the heading "* Detail"; the knowledge contract requires it.)

Each line is =path:line:column: codec/rule: message (fix: ...)=, so editors
that read compiler output can jump to it. The exit status is 0 when no
diagnostic fires, 1 when one does, and 2 on failure.

* Script

=compass check= (=projects/compass.cli=).
