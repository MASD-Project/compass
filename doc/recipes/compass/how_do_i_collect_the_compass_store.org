* Question

How do I reclaim the space compass's store uses?

* Answer

Run =compass gc=. The store under =.git/compass/= is shared by every
worktree; an object stays while any worktree refers to it, and unreferenced
objects older than the grace period (an hour by default) are removed, oldest
first, down to the cap (0 by default). See what would go first:

#+begin_src sh :results verbatim
build/output/linux-clang-release-ninja/publish/bin/compass gc --dry-run
#+end_src

: would remove 49 files, 274565 bytes; store 2685453 bytes in 1227 files

Then collect:

#+begin_src sh :results verbatim
build/output/linux-clang-release-ninja/publish/bin/compass gc
#+end_src

Removing objects costs only speed: the next run parses again what it needs.

* Script

=compass gc= (=projects/compass.cli=, =projects/compass.store=).
