compass-ng is a high-performance, data-oriented re-implementation of the
document-management part of compass from compass-ng. See
[[id:2F71292F-CDB0-4E2E-B50F-4F02E10597C4][Product identity]] for what it is and why.

During the bootstrap phase the documentation is plain org-mode in this
repository. It follows the compass-ng contract verbatim; see
[[id:82F08C3E-D00F-4888-8C11-CC4358AA9FB7][Meta]].

* Folder layout
#+begin_example
doc/
├── compass.org       ← this file; read first
├── meta/             ← the contract: how documents are shaped
├── identity/         ← product vision and scope
├── agile/
│   └── versions/     ← version → sprint → story → task
└── knowledge/        ← cross-cutting reference material
projects/
├── modeling/         ← system-wide models: system model, component architecture
└── compass.<name>/   ← one directory per component (none yet)
#+end_example
