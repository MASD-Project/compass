Durable, cross-cutting knowledge that outlives any sprint. Each page is
a single topic — a definition, a convention, an explanation of how some
piece of the system works — that other documents can link to without
restating it. If you find yourself explaining the same concept in two
places, that concept belongs here.

This index lists the /hub/ of each topic rather than every page in it.
A hub gathers its own pages and says how they relate, so listing both
here would duplicate that work and go stale as pages are added. Follow
the hub for the topic you want; to see every page regardless of topic,
list the =knowledge= tag.

For user-facing documentation see [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][ORE Studio Manuals]].
