* Goal

compass has a public website built from its own org documents (manual,
knowledge, agile pages and component overviews), published by CI on every
change to =main=, built with Emacs org-publish the way ORE Studio's site is.
The machinery that builds a site lives in compass, once, and ORE Studio
builds its own site with it.

* Acceptance

- =compass= ships the site build: the Emacs Lisp ORE Studio keeps in
  =projects/ores.lisp= (=ores-build-site.el=, =ores-site-packages.el=), made
  project-neutral, with the project's name, theme and sections as
  configuration.
- compass's site builds locally with one command and in CI, and is published
  to GitHub Pages from =main=.
- Links between pages resolve on the site as they do in Emacs; a page that
  does not export is reported, not skipped.
- ORE Studio's site builds with compass's machinery, its own copy is deleted,
  and its site does not change in content.

* Decisions

- Emacs org-publish builds the site, as ORE Studio's does, not compass's own
  HTML renderer; the renderer serves documents at run time.

* Out of scope

- Search on the static site; the document service serves search.
