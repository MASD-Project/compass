The =format= engine. A check document says =:ENGINE: format= and names
a formatter compass knows (prettier or clang-format), the candidates for
its program, its style file, and the files it covers. Its codec emits
each covered file as the checkout holds it, the format step runs them
through the format cache the codegen codec uses, and =compass check=
reports each file whose formatted form differs, as
=<check>/unformatted=, at the first byte that differs. A formatting
check's files are the checkout's own, so =compass generate= never writes
them, and a file a check stops covering is never removed. A run after an
edit formats only the edited files.
