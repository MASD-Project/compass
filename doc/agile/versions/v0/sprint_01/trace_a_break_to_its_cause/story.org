* Goal

When a check fails on main, nobody knows which change caused it, or which environment to ask. ORE Studio's commits mostly carry =Story-ID=, =Task-ID= and =Environment= trailers and its pull requests a Story, Task and Environment table, but not all: of the last 200 commits on main, only 98 name their environment.

The story has two parts. First, a check that every commit on a branch, and its pull request, states its story, task and environment, with IDs that resolve to the documents. Second, blame: for a finding already on main, compass traces the likely cause to a commit, its pull request and its environment. How depends on the rule, so each rule names its method: blame the reported line; find the commit that added the subject a missing thing was required for; for drift, a hand edit to the output or an input changed without regenerating; and as the fallback, bisect main's merges running only that codec. Every answer says which method found it.
