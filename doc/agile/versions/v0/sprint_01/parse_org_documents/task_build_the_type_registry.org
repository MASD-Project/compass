* Acceptance

- Every document type in doc/meta is registered with its required keywords and sections.

* Plan

- The registry is data read from the document contract, not code. Each
  =doc/meta/document_type_*.org= page is parsed with =compass.ingest= and its
  =* Contract= section yields the type's name, level, folder, whether it is
  stateful and its =#+todo:= keywords, and its required sections.
- Codegen model types (entity, component, operation, field_group, junction,
  module, family and the rest) are defined by ORE Studio's codegen meta-model
  documents, not by =doc/meta=. They enter the registry from a short declared
  list marked =model=, until the codegen port reads their schemas.
- Data shape: a =type_table= in struct-of-arrays form (name, kind document or
  model, level, stateful, required section names as a range into a names
  column), keyed by interned name. Lookup by name is a sorted search.
- The registry lives in =compass.org= beside the tables it describes.
- =compass-bench types <checkout> --meta <dir>= builds the registry, parses
  every org file, resolves each =#+type:= and reports counts per type and every
  unresolved type with its files. The ORE Studio run is the next task.
