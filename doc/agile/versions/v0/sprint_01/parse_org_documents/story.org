* Goal

Every org file in ORE Studio and in this repository loads into data-oriented tables with full fidelity, typed by a registry built from the document contract.

* Acceptance

- The tables are named and documented before the parser is written: documents, headlines, properties, keywords, blocks, links, inline markup.
- All of ORE Studio's org files parse with no error, and the parse time is recorded against the baseline.
- The type registry is built from doc/meta, and every document's #+type: resolves to a registered type.
- Codegen model types (entity, component, operation, field_group, junction, module, family) are recognised as models.
