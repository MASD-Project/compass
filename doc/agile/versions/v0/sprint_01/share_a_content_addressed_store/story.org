* Goal

A run never re-parses a file whose content any worktree of the repository has already parsed, and a run with nothing changed finishes in under a second.

* Acceptance

- Objects are immutable, keyed by content hash, written by temporary file and rename, and stored under the repository's git common directory.
- Each worktree keeps its own index of path, modification time, size, inode and hash; clean tracked files take their blob ID from git's index.
- A warm run over ORE Studio with nothing changed finishes in under one second.
- Deleting the store loses only speed, never correctness, and a size cap evicts the least recently used objects.
