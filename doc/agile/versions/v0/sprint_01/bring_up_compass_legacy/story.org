* Decisions

- Copy a slice, not the whole tool. Kept: =compass.py=, =doc_index=, =doc_list=,
  =doc_show=, =search_scorer=, =ui=, codegen's =doc_generate.py= and
  =regenerate_backlog_indexes.py=, the =doc_*= templates, and the org-roam
  elisp. Dropped: environments, deployment, systemd, NATS, database, build,
  site, test, PR, review, skills telemetry, timeline and fleet.
- Prune =compass.py= mechanically: remove the dropped commands from =main=,
  then remove every top-level definition no longer reachable, to a fixed
  point. 7,799 lines became about 5,600.
- Keep the code otherwise verbatim, so fixes in compass-ng port across.
