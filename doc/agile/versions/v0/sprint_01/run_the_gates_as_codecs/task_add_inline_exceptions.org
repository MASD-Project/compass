* Acceptance

- An expired exception becomes a diagnostic on the line it covers.

* Plan

- Survey how ORE Studio excuses violations today: baselines, allowlists,
  registry exceptions and comment markers each gate reads. The exception
  format should be able to replace them.
- One comment form for any file type, naming the rule, a reason, an expiry
  date and an approver. It covers the next line, or the same line.
- The codec runtime suppresses a finding that a valid exception covers. A
  missing reason, expiry or approver, an expired date, a malformed exception,
  or one that covers no finding is itself a diagnostic.
- Ratchet mode and =--commit= see exceptions as they are in each tree.
