* Plan

- Enumerate every gate from ORE Studio's =local_checks.py= and its CI
  workflows at one recorded commit, read from a =git archive= copy.
- For each, record what it reads, what it checks, and its class: port as a
  compass check, replace by diff mode (it regenerates and compares, which
  compass's codegen codec now does), or keep as a build gate.
- Time each cheap gate in the archive copy, with the machine load beside each
  number. Take build, database and test gate times from CI run logs.
- Keep the table in an evidence file beside this task, so later tasks can
  pick their ports from it in order of cost.

* Result

Every gate in ORE Studio's =local_checks.py= and CI workflows is classified,
with its baseline time, in the [[id:AFF665C4-739C-4BDB-93BD-9D547351AE4F][gate classification]].

The slowest ports are exported-types (62 s), sql-hygiene (50 s, run twice in
CI through validate-sql-schema), tangle-shell (41 s), paste-blocks (29 s),
enum-attributes (20 s), reachability (13 s), unity-collisions (12 s),
tangle-templates (11 s) and portable-stop (11 s). The three diff-mode gates
alone take about 22 minutes, and compass's codegen codec already replaces
their work.

Open questions, recorded in the evidence:

- The tangle gates are ports only if compass tangles as Emacs does. It does
  for templates (171 of 171), but tangle-shell was not checked.
- 28 ports regenerate artefacts that are not codegen output. Each becomes diff
  mode once compass has a codec for it.
- site-page becomes diff mode if compass's HTML export replaces Emacs.
- At this ORE commit 11 gates fail on real problems, including the 24 drift
  files, a stale PlantUML schema, a stale backlog index and three failing
  codegen tests.
