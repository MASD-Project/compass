* Result

- *D8.* The store packs objects, manifests and results into append-only
  =.cpk= packs, each with its index at the end, published by one rename. Each
  writer appends to its own temporary file, so writers share nothing; a
  geometric repack under =flock= keeps the pack count logarithmic, and =gc=
  rewrites the packs to drop unreferenced entries. A store in the old layout
  is read as cold, and =gc= deletes it. =--version= shows =store layout 2,
  packs 1=.
- *D1.* =rls_coverage= in =compass.sql= reports =missing_rls= and
  =missing_party_isolation= as the Python gate's =--strict= does, honouring
  =validation_ignore.txt=; on ORE Studio =67803175ce= it reports the same
  eight warnings on the four trading tables.
- *D3.* =--commit= on a commit without =.compass.org= warns and uses the
  working tree's.
- *D5.* =compass hook= reports only findings the last check's record lacks;
  =--all-findings= restores every finding.
- *D6.* =generate= warns when a rewrite removes three or more lines its own
  output lacks from a file someone edited.

An install changes for the pilot: the first check is cold, =compass-ng gc=
deletes the old store's files, =rls_coverage= must be enabled to replace the
Python er-diagram gate, and the hook stops blocking on old findings.

Decisions to revisit: formatted results are named by no record, so a gc an
hour after the last check drops them and the next check reformats (about 50
s on ORE); RLS_003 is not ported; packs are not fsynced.
