* Acceptance

- The crosscheck gates that regex raw model files read the models compass.model loads, run per model, incrementally, as one model-rules pass where they share data.
- Rules about facts the model states (entity binary types, generated column references, protocol twins' model half, money columns, http areas, model drift) are checked against the model or the codegen context, not regexes over generated files.
- The curve wiring is computed once per run instead of four times, and the convention terms once instead of three.
- Every moved gate gives the same findings on ORE Studio as before, except where a regex was wrong, each change stated; the hook on a model edit and the cold check are measured before and after.

* Plan

- Follow section 3 of =evidence/gate_review/plan.md= and =crosscheck.md=.
- Move one gate at a time onto the loaded models, comparing findings on the
  ORE copy after each; then merge the repeated derivations.
