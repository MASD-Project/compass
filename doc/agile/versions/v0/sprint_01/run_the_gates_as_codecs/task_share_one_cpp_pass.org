* Result

One C++ lexer (=ops::lex=: raw strings with delimiters, encoding prefixes,
digit separators, line splices, =#if 0= regions) replaces the six blankers,
and one per-file model (=ops::model_of=: includes, macros, namespace-scope
declarations, class and enum heads, names written) serves portable_stop,
exported_types, forward_declarable_includes, stream_coverage,
unique_type_names, unity_collisions, the registrars, the shell gates,
translation_unit_budget and test_case_reachability. Each gate builds only the
parts it reads.

- enum_attributes is merged into exported_types: one pass, two rules. Its
  rule is now =exported_types/visibility_macro_on_enum=.
- forward_declarable_includes decides each header in its map step, from a
  =types= option whose default is ORE Studio's list.
- stream_coverage keeps each file's declarations, not its text.
- unity_collisions keys functions by parameter types, so overloads a unity
  build compiles are not reported.

C++ findings on ORE Studio are unchanged; the cases the old blankers got wrong
(character literals, attribute heads, multi-line declarations, comments) are
covered by planted tests.

An install needs ORE Studio's =.compass.org= to drop its =enum_attributes=
row; =forward_declarable_types.list= is no longer read.
