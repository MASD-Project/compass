* Acceptance

- The table is generated and the list of unenforced memories is reported.

* Plan

- Give every codec rule metadata: its identifier, a one-line statement, and
  the memory or document that states the rule in prose, where one does.
- Generate the rule table as a codec output, an org page listing each rule
  with its codec and the memory it enforces, so it can never drift from the
  checks.
- List the memories in =doc/llm/memory/= (and ORE Studio's, when compass runs
  there) that no check enforces, as the candidates for the next checks.
