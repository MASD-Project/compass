* Result

Every rule carries its statement and the =:ID:= of the memories or documents
it enforces, in its codec descriptor. The =rule_table= codec generates
=doc/knowledge/compass/rule_table.org= from them, with a section of the
memories no rule cites, so =compass check= reports the page when a rule or a
memory changes. Unenforced memories are listed, not reported as findings: a
memory without a check is work not yet done, not a defect in the tree, and
118 warnings on every ORE check would drown the real findings.

The most checkable unenforced ORE Studio memories, as candidates for the next
checks: definer functions revoked from public, no reads or writes of another
component's tables, no migration scripts, no JSON columns, paged lists, no
forwarding headers, no PR tables in stories, one Result per task, no history
compare panel, and the reserved dashboard name.

This repository's =.compass.org= changed with it: the output root is the
checkout, so the page lands where it is committed; =document_index= writes
under =build/output/=; and =tangle= is off, because the 85 files it wrote
under =build/output/compass= are used by nothing. =tangle_check= still runs.

Decisions to revisit:

- The table lists every rule compass ships, not only enabled ones, so a memory
  cited by a disabled gate counts as enforced.
- Drift is one row for every codec that writes files, so memories about one
  generator cannot be attached to it.
- Several memory links are judgement calls, listed in the agent's notes on
  the PR.
