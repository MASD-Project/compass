* Goal

One compass check command runs every ORE Studio gate that needs no build in seconds, locally, in CI and after each edit, with ratchet mode, inline exceptions and checks that can be proven on past commits.

* Acceptance

- Each of the roughly 105 ORE Studio gates is classified as port, replace by diff mode, or keep as a build gate.
- Every ported gate gives the same verdict as its ORE Studio original on the same commit.
- All ported gates over the whole ORE Studio tree run in under 10 seconds.
- Ratchet mode fails only on diagnostics that are new relative to the merge base.
- Inline exceptions carry a reason, an expiry and an approver; expired or unapproved exceptions are diagnostics.
- A check can run against any past commit, reading content from git's object store.
- A Claude Code hook runs the checks on changed files after each edit and reports in under one second on a warm cache.
- The rule table pairing each rule with its enforcing check is generated, and memories without a check are listed.
