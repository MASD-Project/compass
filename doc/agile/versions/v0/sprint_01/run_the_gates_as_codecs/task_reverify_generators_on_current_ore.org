* Acceptance

- Every generator codec writes every file its Python generator writes on ORE Studio's current main, byte-identical, and a plant in each output is drift.
- Each difference found is fixed, or recorded with its cause when it is ORE Studio's drift rather than compass's.
- A repeatable script runs the comparison, so it can be rerun when ORE Studio changes a generator.

* Plan

- The pilot found curve_sections_wiring missing two outputs ORE Studio
  added after 545cafca45, the tree every port was verified on.
- For each generator codec: run its Python generator on a read-only export of
  ORE Studio main, list every file it writes, and compare with compass's
  outputs for the same tree; plant a change in each output.
- Build the comparison as a script kept in the repository.
