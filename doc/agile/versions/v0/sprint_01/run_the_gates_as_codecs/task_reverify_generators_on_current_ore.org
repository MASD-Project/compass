* Result

Every generator codec still matches its Python generator on ORE Studio main
05e6d19756 (the merge of ORE Studio PR #4839): the same files, byte for byte,
and a plant in each is drift; codegen reports no drift against ORE's
committed tree. No compass fix was needed.

=build/scripts/verify_generators.sh= reruns the comparison on any ORE export:
for each generator it runs =compass generate --out= with only that codec, runs
the Python generator in write mode on a clone, compares the files, plants a
change in each output and requires drift on exactly those files, and probes
for outputs a generator skips when they are current. It exits 1 on any
difference, so a change to an ORE generator can be checked before an install.

Known blind spots: an output touched only on a line the plant leaves alone
(skill levels' =#+level:= lines, deliberately not ported), and outputs a
generator skips when its JSON or XML inputs are unchanged.
