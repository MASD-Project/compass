* Acceptance

- =compass --version= names the release, the commit, whether the tree was dirty, and the store formats it reads and writes.
- A new commit recompiles and relinks nothing.
- One compass, shared by every environment, installs behind =~/.local/bin/compass= in one atomic step, and a dirty build installs only when asked.

* Plan

- Follow ORE Studio's =cmake/generate_version.cmake=: a target run on every
  build writes a stable =version.cpp= (copied only when different) and a
  =key=value= manifest beside the binary with the commit, the dirty flag and
  the branch. The binary reads the manifest at runtime from beside its own
  resolved path, and reports "unknown" when it cannot.
- Add the store formats (dependency record, action format, written outputs,
  worktree index, format cache) to =--version=; they are compiled constants.
- An install script copies the binary and its manifest into
  =~/.local/opt/compass/<commit>/= and repoints =~/.local/bin/compass= with
  an atomic rename, refusing a dirty tree unless told otherwise.
- Prove that a commit changes no compiled file: build, commit, build again,
  and see nothing recompile or relink.

* Result

=compass --version= names exactly which build is running, and a commit or a
dirty tree recompiles and relinks nothing. As in ORE Studio, a build step
writes =compass.manifest= beside the binary with the commit, commit time,
dirty flag and branch, copied only when it changes, and compass reads it at
runtime from beside its own resolved path; the build time is the binary's own
mtime. CI builds take the commit from =COMPASS_BUILD_*= variables.

=build/scripts/install_compass.sh= installs one shared compass for every
environment: the binary and its manifest in =~/.local/opt/compass/=, with
=~/.local/bin/compass= linking to it. It refuses a dirty build unless
=--allow-dirty= is given and records the install time in the manifest. The
recipe =how_do_i_install_compass.org= covers building, installing and reading
=--version=, and =doc/ore_studio/move_an_environment_to_compass.md= guides an
ORE Studio environment onto compass.

Decisions to revisit:

- The binary and the manifest are each renamed atomically but separately, so
  a run in the moment between them pairs the new binary with the old manifest.
- The release number stays a compile definition and changes only with
  =project(VERSION)=.
