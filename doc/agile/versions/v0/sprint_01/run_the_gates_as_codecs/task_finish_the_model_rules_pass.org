* Result

The five gates read structure instead of regexes. Findings on ORE Studio are
unchanged except where a regex was wrong.

- open_reads reads its allow-list from the parsed org table.
- route_units' rules moved into =model_rules=: =route_units/unregistered_unit=,
  =twice_registered= and =missing_unit= are now =model_rules/...=. An opt-in
  in a heading drawer no longer counts, since codegen reads only the file
  drawer.
- generated_column_refs and entity_binary_types are per-model document codecs
  over =ops::generated_shape_of=, which loads the model and runs codegen's own
  context steps. Findings sit on the model's headings. =too_few_compared=,
  =min_compared= and =no_table= are gone.
- marketdata_identity_columns reads the identity table's columns from its
  model, so it fires before code is regenerated.

An install needs ORE Studio's =.compass.org= to drop its =route_units= row and
its runner map to send route-units to =model_rules=.

generated_shape mirrors three things from ORE's templates by hand: the
repository row's member types, the create script's column list and the class
members. A template change there needs a matching edit in compass.
