* Result

Six of the seven approved drops are made: paste_blocks, the C++ half of
subject_conformance, model_sql_types (whole: every create script a model
claims is generated, so drift covers them), model_drift's two rules the
loader throws first, skill_recipes, skill_level_tags, and prototypes'
react_tree and no_discovery. None of the dropped rules had a finding on ORE
Studio.

component_docs/missing_section is kept. Its drop was approved as a
duplicate of required_sections, but that holds only for =#+type: component=,
and all 128 of ORE Studio's overviews are =#+type: ores.codegen.component=,
which has no contract; dropping it would leave them with no section check.

An install needs ORE Studio's =.compass.org= to lose the rows for
skill_recipes, paste_blocks, model_sql_types and skill_level_tags, or every
run stops; an inline exception naming a dropped rule becomes malformed.
