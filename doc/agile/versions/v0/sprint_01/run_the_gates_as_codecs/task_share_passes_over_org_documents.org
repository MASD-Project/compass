* Result

The org gates read compass's parsed tables instead of regexes. A scan can now
map a parsed document (=map_document=) as well as bytes, reusing results by
the document's content ID. lint's scan is the ID-link graph: each page's fact
holds its type, title, tags, level-1 sections, =:ID:= properties, generated
markers and id links, and one reduce runs lint's rules, the pattern rules and
=missing_backlink=. heading_numbers, org_links and component_docs read the
tables and keep their own rule names.

- =pattern_uses= is folded into lint: its rules are now
  =lint/pattern_unknown_use=, =lint/pattern_one_way=,
  =lint/pattern_not_a_pattern= and =lint/pattern_shared_id=.
- =structure_notes= no longer rewrites pages; a missing back-link is
  =lint/missing_backlink=, reported at the page's See also heading with the
  line to add.

Findings on ORE Studio are unchanged; the changes the planted defects showed
are places the regexes were wrong (links and markers inside blocks, wrapped
link labels, =TODO= headings, bare back-links).

An install needs ORE Studio's =.compass.org= to drop its =pattern_uses= and
=structure_notes= rows; the 417 pages structure_notes wrote stay on disk.
lint still costs about 190 ms in the hook with an unchanged fact, inferred to
be the scan table's decoding; cutting it needs runtime work.
