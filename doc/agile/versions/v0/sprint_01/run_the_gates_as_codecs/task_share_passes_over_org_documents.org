* Acceptance

- The org gates read compass's parsed tables (headings, keywords, links, blocks, tables, drawers) instead of regexes over org text, wherever the parse answers the question.
- lint, pattern_uses and structure_notes share one ID-link graph pass; structure_notes becomes a missing-backlink check instead of rewriting pages.
- Every org gate gives the same findings on ORE Studio as before, except where a regex was wrong, each change stated.
- An org edit in the hook costs less than today, and the cold org-gate time falls, measured at a stated load.

  pattern_uses and structure_notes.
