* Acceptance

- =compass hook= reports in under one second warm for every single-file edit kind in ORE Studio, including codegen models and templates, C++ headers and new files.
- The hook still matches a full check on every edit of the comparison set, and =compass check= still reports the same 24 codegen drift files.

* Plan

- Make code generation incremental: a model edit re-renders only that model's
  outputs and those of the models that read it, and a template edit only that
  template's outputs. Each model's contexts and outputs are cached under a key
  of its recorded reads, including reads served from the shared load cache,
  and of the derived prework it uses (entity registry, checkout registry,
  template graph, catalogue).
- Cut the C++ and SQL scans that still cost most on an edit (stream_coverage,
  forward_declarable_includes, exported_types, populate_refs,
  test_case_reachability) and the cost of a new file, which joins listings.
- Keep the 24 codegen drift files and the hook-versus-check comparison exact.
