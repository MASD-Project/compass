* Acceptance

- Each of xml-bindings-drift, file-types-seed, ore-parameters-seed, ore-element-map, ore-parameter-value-sets and parameter-value-sets-only has a written decision: what it protects, whether that still needs a gate, and how compass does it.
- Where the Python's output depends on accidents (object identity, directory walk order, dict order), the decision fixes the intended order and says what changes in ORE Studio's committed files.
- Every gate kept is a compass codec at a fraction of the original's time.

* Plan

- For each of the six gates, read the generator and what consumes its output,
  and write down what it is trying to achieve: the invariant it protects and
  the artefact it produces.
- Judge whether the gate makes sense as it is: whether the artefact needs to
  be committed, whether the check duplicates another gate or a codec compass
  already has, and where the Python's output rests on accidents (object
  identity, dict order, directory walk order, comprehension-built tables).
- Design the compass version for the intent, not the script: a fixed,
  documented order; one pass over the data shared with gates that read the
  same inputs; and the cheapest representation of the check.
- Record each decision in an evidence file, port the gates kept, and list
  the changes the intended order makes to ORE Studio's committed files.

* Result

Each of the six gates has a written decision in [[id:9BF8E18C-EB46-4C08-B060-9C1165D2646E][the remaining generator gates
evidence]], judging what it protects rather than copying the Python.

- *ore-parameter-value-sets, ore-element-map, parameter-value-sets-only:
  merged.* They read one fact three times, judged the sets twice with
  different messages, and reparsed a 370 KB JSON file per leaf. compass
  resolves the model once (=ops::value_sets=); =ore_value_sets= writes the
  three seeds and =parameter_value_sets= reports each rule once. The curve
  column and convention term rows are shared with their codecs.
- *xml-bindings-drift: keep the drift check, drop its determinism run.* The
  second run proves nothing; clang-format is the real cost, which compass's
  format cache removes once the generator is ported. Not ported in this task.
- *file-types-seed: keep, after ORE fixes its locale-dependent digest and
  curates a name its walk order breaks a tie on.* Not ported: its table is
  built by code.
- *ore-parameters-seed: stays in Python* until its texts are data files.

The ORE Studio guide now lists these fixes for the environment to make.

Decisions to revisit:

- =ore_value_sets= writes nothing when any set rule fails, stricter than the
  Python.
- Curation findings are anchored at line 1 of =generate_value_sets.py=.
- A codec's results are keyed by its hand-set version, so a development build
  that changes a codec without bumping it replays stale stored results. With
  one shared store across ORE Studio's environments, that becomes a real
  hazard and needs a structural fix.
