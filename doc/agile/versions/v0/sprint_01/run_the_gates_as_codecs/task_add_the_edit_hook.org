* Acceptance

- The hook reports in under one second on a warm cache for a single-file edit in ORE Studio.

* Plan

- Add =compass hook=: it reads Claude Code's =PostToolUse= payload on stdin,
  takes the edited file, and runs only the checks whose recorded inputs
  include that file, reporting the findings on it back to the agent.
- A full warm check of ORE Studio takes 6 to 8 s, about 1.4 s of it reading
  the dependency record, so the hook needs an index from file to the codec
  units that read it, read without loading the whole record.
- Document the hook settings in a recipe. Installing the hook into this
  repository's or ORE Studio's Claude Code settings is a separate decision.

* Result

=compass hook= reads Claude Code's PostToolUse payload, runs only the units
whose recorded inputs include the edited file, and reports the findings on or
caused by the edit as a =block= decision; it fails open with a note. It gives
a full check's findings on every edit tried.

The acceptance is met for unrelated files, CMake, org documents, skill pages
and several C++ edits, but not yet for codegen models and templates (2.2-2.8
s), most C++ header edits (1.4-1.6 s) or new files (about 2 s). That work moves
to [[id:3AF7E12E-3167-43E2-BADF-0178E90A74BB][Bring the edit hook under one second]].

- The dependency record (version 5) indexes its unit heads, so one unit loads
  without reading the 268 MB of output contents; the index reads in about 55
  ms.
- Scans: a corpus codec maps each file to findings and a fact, cached by
  content ID, and reduces the facts. Thirteen gates are scans now, which cut a
  header edit's gate time from 2.5-4.5 s to 70-650 ms and the full warm check
  from 6.5-7.6 s to about 4.1 s.
- The hook lists the checkout from the last check's listing record unless the
  edit creates a file, and the worktree index keeps every hashed file's ID.
- Codegen renders on every core but is still one unit.

The hook is not installed in this repository's or ORE Studio's Claude Code
settings; the recipe =how_do_i_check_edits_as_claude_code_makes_them.org=
holds the settings.

Decisions to revisit:

- The hook writes nothing and trusts the last check's listing and record, so
  a change made outside the edit is seen only at the next check.
- =stream_coverage= keeps call-name lists for every file, about 4.5 MB.
- A check right after a codegen change takes about 10 s, mostly decoding and
  writing the 193 MB codegen result.
