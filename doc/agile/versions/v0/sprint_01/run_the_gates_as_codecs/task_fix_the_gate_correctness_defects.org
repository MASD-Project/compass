* Acceptance

- A generator that cannot produce its output reports a finding, so =compass check= fails where the original gate failed; a refusal after a good run never deletes the committed file.
- The licence year is an input of every codec that writes it, so a warm and a cold run give the same bytes, and a change of year is visible as one deliberate change.
- Each copied Python bug listed in =evidence/gate_review/plan.md= section 1 is fixed or justified, with the verdict change on ORE Studio stated.

* Plan

- Follow section 1 of =evidence/gate_review/plan.md=.
- Refusals: let one codec unit emit both files and findings, or give each
  generator a diagnostics twin; decide by what the runtime and the record need,
  and make a refusal keep the previously written file.
- Licence year: make it a configured or recorded input, never the clock.
- Copied bugs: fix each with a test that fails on the bug, and diff the
  verdict on the ORE copy before and after.
