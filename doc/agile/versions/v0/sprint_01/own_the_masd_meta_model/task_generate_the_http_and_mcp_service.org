* Goal

Copy ORE Studio's route with its catalogue declaration, its router and route
builder with their start-up gates, and its typed bodies from ORE Studio's main
into a MASD template family, =masd.cpp.http-service=, rendered for compass
only. Then generate Serve the documents' HTTP and MCP service from its
operation models with it: one route per message, declared through the copied
builder with its tool, area, entity, whether it writes, its parameters and its
typed body, and handled by calling the query function in process; and a tool
provider for compass's =/mcp= that lists one tool per route, built from the
same declarations. The query functions and the caller read from gateway
headers are written by hand; there is no hand-written dispatcher. compass
does not wait on ORE Studio. See
[[id:AF30B206-2FAB-435F-819F-9EC652D4E40D][Design: aligning the document service with ORE Studio's HTTP and MCP]].

* Acceptance

- =masd.cpp.http-service= holds the route, =route_catalogue=, the router and
  route builder with their start-up gates, the typed bodies and the OpenAPI
  registry, copied from ORE Studio's main. The task records the ORE Studio
  commit it copied from, and every change from it is a divergence the design
  records.
- Every route of the service is generated, and the copied router's start-up
  gates accept it: a tool, an area, an entity and whether it writes on every
  route, a typed body on every route that takes one.
- The generated tool provider lists one tool per route, with the models'
  descriptions and the routes' input schemas.
- =GET /v1/catalogue= answers every route's declaration and input schema.
- =compass generate= on compass reports nothing to write.
