* Goal

Generate Serve the documents' HTTP and MCP service from its operation
models, on the family [[id:A2D4D196-1BF0-48F1-8C9D-7096651F94E1][Move the HTTP and MCP service machinery to MASD]] brings from ORE Studio: one route per
message, declared through ORE Studio's route builder with its tool, area,
entity, whether it writes, its parameters and its typed body, and handled by
calling the query function in process. compass's =/mcp= is the moved endpoint
with a tool provider that lists one tool per route, built from the same
declarations. The query functions and the caller read from gateway headers are
written by hand; there is no hand-written dispatcher. See
[[id:AF30B206-2FAB-435F-819F-9EC652D4E40D][Design: aligning the document service with ORE Studio's HTTP and MCP]].

* Acceptance

- Every route of the service is generated, and the moved router's start-up
  gates accept it: a tool, an area, an entity and whether it writes on every
  route, a typed body on every route that takes one.
- An MCP client lists one tool per route, with the models' descriptions and
  the routes' input schemas, and the MCP conformance runner passes.
- =GET /v1/catalogue= answers every route's declaration and input schema.
- =compass generate= on compass reports nothing to write.
