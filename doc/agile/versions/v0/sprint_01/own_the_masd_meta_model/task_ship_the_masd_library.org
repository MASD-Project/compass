* Goal

ORE Studio must read the MASD meta model from compass without a copy.
This task installs the library under =share/compass/masd= in every package,
resolves =@compass= against the running executable, and lets =library= list
several directories, compass's first and the project's on top, with the licence
and product taken from the project. [[id:7FD52505-1436-4925-A1DE-4A3EC88F0133][Investigation: How compass generates itself]] compares it with a submodule and
a package of its own.
