* Goal

Describe compass's database in models: a MASD entity context
that derives names, key shape, column types and the index and check lists
without ORE Studio's tenancy and history; the features =schema=, =key_kind=,
=written_by=, =values=, =opclass=, =on_delete=, =computed= and =generated=;
the profiles =content-addressed-row=, =owned-child-row= and
=activity-record=; and one model for each table of the =corpus=, =test= and
=activity= schemas. [[id:7FD52505-1436-4925-A1DE-4A3EC88F0133][Investigation: How compass generates itself]] works =corpus.document= and =activity.run=
through.
