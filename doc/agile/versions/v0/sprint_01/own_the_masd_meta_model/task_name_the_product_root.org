* Goal

compass's codec, its docs codecs and =compass add= name ORE Studio's
physical-space root =ores=, its library path and its =projects/modeling=
directory in code. This task makes them configuration, so the same tools serve
a project whose product is =compass=. It is the first step of
[[id:7FD52505-1436-4925-A1DE-4A3EC88F0133][Investigation: How compass generates itself]]'s order of work, and nothing else in the story can start before it.
