* Goal

Every type compass models reads and writes JSON through generated code: row
types (whose =jsonb= columns are JSON already), enums as their names, and the
service's request and response messages. Each message also gets a generated
JSON Schema, which the MCP tool descriptions embed. No JSON is encoded or
decoded by hand anywhere in compass.

* Acceptance

- A template family generates, per modelled type, a JSON writer and a reader
  that rejects unknown and missing required fields with the field's name.
- Round-trip tests are generated with them: write then read gives the value
  back, for every row type, enum and message.
- Each message's JSON Schema is generated and validates what its writer
  writes, checked in a test.
- The JSON library is chosen in this task, measured against the design's
  default (nlohmann-json), and is a vcpkg dependency that builds on Linux,
  macOS and Windows.
- ORE Studio's wire-codec templates are reused where they fit, with the
  product root as a parameter, and the choice is recorded.
