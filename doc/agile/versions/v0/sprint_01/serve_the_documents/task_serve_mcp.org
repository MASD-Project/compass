* Goal

=compass serve= answers MCP's Streamable HTTP transport at =/mcp= exactly
as ORE Studio's ores.http does, because it is the same endpoint, generated from
the family [[id:A2D4D196-1BF0-48F1-8C9D-7096651F94E1][Move the HTTP and MCP service machinery to MASD]] moves into MASD. Its tool provider lists one tool
per route, from the routes' catalogue declarations, and calls the route's
query function. See [[id:AF30B206-2FAB-435F-819F-9EC652D4E40D][Design: aligning the document service with ORE Studio's HTTP and MCP]], sections 1 and 2.

* Acceptance

- =/mcp= serves the protocol revisions, session handling, status codes and
  JSON-RPC error codes ORE Studio's endpoint serves, and passes the official
  MCP conformance runner with the same expected results.
- =tools/list= answers one tool per route, named as the route declares it,
  with its summary, input schema and =readOnlyHint=; =tools/call= calls the
  same query function as the route.
- A session is owned by its subject and actor; locally the actor is =mcp:=
  and the client's name from =initialize=.
- A request without a view is refused.
