* Acceptance

- A configure, build and test with the default preset succeeds from a clean checkout.

* Plan

- vcpkg is a git submodule at =vcpkg/=, as in ORE Studio, used in manifest mode
  from =vcpkg.json=. The only dependency for now is =catch2=.
- =CMakePresets.json= follows ORE Studio's shape: a hidden base, Ninja, C++23,
  =build/output/<preset>=, compile commands exported, the vcpkg toolchain. The
  presets are =linux-clang-debug= and =linux-clang-release=, with matching build
  and test presets.
- The root =CMakeLists.txt= declares the project, enables testing and adds
  =projects/=. =projects/CMakeLists.txt= adds each C++ component by name; it
  never globs, so =compass.legacy= and =modeling= are not CMake targets.
- The first component is =compass.platform=, a simple component in the
  foundation layer. It holds one facet, =filesystem=, with a read-only
  memory-mapped file view. The baseline parse harness reads the ORE Studio
  tree through it.
- Targets follow the component architecture: =compass.platform.lib= and
  =compass.platform.tests=. The test maps a file with known bytes and an empty
  file.
- Builds run with =-j2=, per the project memory.

* Review

* Result

- vcpkg is a submodule in manifest mode with Catch2 as the only dependency.
  The presets cap builds at two jobs and vcpkg at two concurrent installs, so
  the -j2 rule holds without anyone passing the flag.
- =compass.platform= is the first component: a static library with the
  =filesystem= facet and =mapped_file=, a move-only read-only view over a
  memory-mapped file. It refuses non-regular files and never calls mmap for an
  empty file.
- A clean =cmake --preset linux-clang-release=, build and =ctest= pass. The
  test executable runs 7 cases with 20 assertions, and each of six deliberate
  defects in =mapped_file= made it fail.
- A clean configure takes about 10 s with Catch2 in the vcpkg binary cache and
  about 60 s without it.
- =compass add component= writes ORE Studio's codegen component type, so the
  component overview was written by hand with =type: component=.
