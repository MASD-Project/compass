* Acceptance

- The include graph gives transitive fan-in and fan-out per file and total lines compiled.
- Rebuild cost weights fan-in by measured compile time from .ninja_log or -ftime-trace, and hotspots weight it by change frequency from git log.
- Component metrics are computed: Lakos levels, CCD, ACD and NCCD, Martin's coupling and instability, and include cycles.
- Complexity metrics are computed per function and type: cyclomatic and cognitive complexity, length, parameters, nesting, and struct member count.
- SQL facts are extracted: tables, columns, foreign keys, functions and policies.
- Changed files get a tree-sitter syntax check on every run, and a clang -fsyntax-only check on demand.
