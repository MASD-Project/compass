* Goal

Nothing compass-ng writes into a project sends its reader to a script the
project has deleted. When ORE Studio deleted the Python generators whose
gates compass-ng ports (#4946, #4950), the codecs still reproduced those
generators' banners and fix messages: generated SQL, headers and pages said
generate_value_sets.py, generate_output_catalogue.py and the like. This
sweeps those texts and adds a rule that reports the next one.

* Acceptance

- No banner, refusal or fix message of a codec names a script missing from
  ORE Studio's main after #4950.
- A regenerated file differs from the one it replaces only in its banner
  lines.
- names_missing_file, a rule every files codec declares, reports a script
  named in the header of a generated file that the checkout lacks.

* Plan

- Listed the 86 script names in compass's sources and the 31 missing from
  ORE Studio's tree at #4950's head; rewrote those that codecs emit, the
  banners of the value sets, convention kind terms, output catalogue and
  script library seed, and their refusals, keeping each banner's line
  count.
- The rule reads only a generated file's header, its first twenty lines,
  where a codec says what generated it: text a codec copies from its
  inputs further down is the inputs' own. Read over whole files, it
  reported compass's rule table and document index, which copied the title
  of an ORE Studio memory naming validate_schemas.sh; the memory was
  removed.
