* Acceptance

- On ORE Studio's main the codec reports the same populate files and
  tables as =check_single_writer.py=.
- The script's exceptions become =compass:except= comments that excuse
  every finding, with no exception left stale.
- An edit to one SQL file maps that file alone.

* Plan

- A scan codec in =compass.crosscheck=, modelled on =entity_writes=. A
  file's fact is its role, publish or populate, and each table it inserts
  into with the line of its first insert. The reduce step intersects the
  two roles.
- Inserts are read as the script read them: block comments are removed
  first, then line comments, keeping each kept byte's offset, so the
  finding lands on the real line.
- The script's exception list, nine tables with reasons, becomes inline
  =compass:except= comments, one per populate insert, as every other
  ORE exception is written. The runtime's stale rule replaces the
  script's check for exceptions that excuse nothing.
