* Goal

Every ORE Studio gate that guards the tree runs in compass-ng, so ORE
Studio can delete the Python scripts behind them. A comparison of ORE
Studio's local checks and CI workflows with compass-ng's codecs on
2026-11-21 found two gates nothing in compass-ng covers: single-writer,
which ran only in CI, and xml-bindings-drift, whose port was decided in
the gates-as-codecs story but not done.

* Acceptance

- Each ported gate reports, on ORE Studio's main, what its script reports.
- A generator gate's output is byte-identical to the committed files, so
  its drift rule replaces the script's comparison.
- ORE Studio has what it needs to switch each gate over: the codec name to
  enable and any exception comments its script's lists become.
