* Result

=--trace-children-skip=/usr/*,/bin/*= keeps git and the other system
programs out. The shell a script test starts as is the program memcheck
runs, not a child, so bash, and the dash that interprets the formatter
stand-ins, are suppressed on their allocators (=xmalloc=, =ckmalloc=,
=ckrealloc=) and their own frames. The store's concurrency test forks
six writers that run store code and =_exit=; each reported the parent's
whole heap as still reachable, 5,670 stacks in all.
=--child-silent-after-fork=yes= silences such children. A run of bash
under memcheck that execs a copy of bash outside =/usr= reports the
copy's heap with the option on as with it off, so an exec'd child is
still checked.
