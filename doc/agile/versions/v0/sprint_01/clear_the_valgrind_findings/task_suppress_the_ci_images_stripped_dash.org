* Goal

The debug nightly's memcheck reports nothing for the tests that run a fake
formatter. On 2026-11-20 it reported 237 potential leaks on CDash (build
4594760): 16 in each of twelve =format_files= tests and 9 in each of five
CLI format and codegen tests. Each test stands a =#!/bin/sh= script in for
the formatter; the script is not under =/usr=, so memcheck follows it into
the dash that runs it.
