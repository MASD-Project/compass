* Result

ORE Studio's file holds 204 rules. compass needs the four it already had:
CMake, the LLVM coverage runtime, glibc's atexit nodes and Catch2's report
stream. The rest cover Boost, Qt, GLib, NATS, OpenSSL and libpq, none of
which compass links; nothing in it covers PCRE2, the shells or libstdc++'s
exception pool, which compass needed. The checker gained one rule of
valgrind's: a generated suppression writes a frame of no object as
=obj:*=, which valgrind matches as the object name =???=.
