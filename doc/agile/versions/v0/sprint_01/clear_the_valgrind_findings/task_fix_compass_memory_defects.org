* Result

Two fixes, neither a memory defect. =run_program= let =posix_spawnp=
report a missing program, which it does only when the child shares the
parent's memory; under valgrind the spawn is a fork, it succeeds, and the
child exits 127, so the test failed and its child reported 384 stacks.
=run_program= now resolves a bare name on =PATH= first and throws
=ENOENT=. The store test set a file's time to its index entry's and
assumed git had written the index in the same second; on the nightly of
2026-11-19 the two were a second apart. The test now gives the index
file the entry's time. Both pass natively and under memcheck.
