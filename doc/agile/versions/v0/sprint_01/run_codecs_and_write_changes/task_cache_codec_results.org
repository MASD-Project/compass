* Acceptance

- A second worktree on the same commit reuses the first worktree's codec results without running the codecs.

* Plan

- A codec unit's result is cached in the shared store under an action key:
  the hash of the codec's name, version and configuration hash and of the
  unit's sorted inputs (key and content ID, misses included). The value is the
  unit's outputs: file bytes and diagnostics, as one object.
- Before running a unit, the runner computes its key from the inputs the
  dependency record says it read and checks the store; a hit restores the
  outputs and records the unit as cached. A unit with no record in this
  worktree runs once to learn its inputs, unless another worktree's result can
  be found by a key that does not need them (corpus units keyed by their type
  set).
- Collection keeps an action object while any worktree's dependency record
  names its key; otherwise it is an unreferenced object and ages out like the
  rest.
- =compass-bench codecs= reports units ran, skipped, and taken from the cache.
  The test: two worktrees of one repository on the same commit; the second
  runs no unit that the first already ran.
