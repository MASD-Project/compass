* Acceptance

- A second run with no input change writes no file and changes no modification time.

* Plan

- A sink takes the run's file outputs and writes them under an output root,
  each through a temporary file and a rename.
- An output is written only when its content hash differs from the hash
  recorded for that path, or when the file on disk no longer matches the stat
  data recorded after the last write: a hand-edited or deleted generated file
  is restored. An output that is written neither way keeps its modification
  time, so the build does not see it as changed.
- compass owns the paths it wrote. A path recorded as written by a codec that
  the codec no longer produces is removed, so a deleted model removes its
  generated files; files compass never wrote are never touched.
- The record of written outputs (path, hash, stat) is per-worktree state beside
  the dependency record, rewritten only on change.
- =compass-bench codecs --write <root>= runs the sink and reports outputs
  written, unchanged, restored and removed, and their time.

* Result

- The sink in =compass.codec= writes an output only when its hash differs from
  the recorded one, or when the file on disk is missing or its stat data no
  longer matches (a hand edit or deletion is restored). Unchanged outputs keep
  their modification time, so the build does not see them change.
- compass removes only the files it wrote and a codec no longer produces; one
  edited by hand after compass wrote it is kept and reported. Directories left
  empty are pruned up to the root.
- The record at =<gitdir>/compass/outputs= holds path, codec, hash and stat per
  output and its output root; a record for another root is ignored. A lost
  record means comparing by content, not rewriting.
- Refused before anything is written: absolute paths, empty, =.= or =..=
  components, a path two codecs produce, and (added in review) a path through
  a symbolic link under the root, which could have written or deleted outside
  it.
