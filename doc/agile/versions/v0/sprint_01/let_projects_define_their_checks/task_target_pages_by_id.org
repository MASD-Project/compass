* Goal

A project can rename or move any page a compass codec writes or reads. ORE
Studio retitled "Which trade types ORE carries and ORE Studio holds" and could
not rename its file to match: =trade_type_coverage= named the page by a path
built into compass, and refused with "the note does not exist". The
=title_file_mismatch= lint will ask every file name to match its title, so
every page a codec targets must be renameable without a compass change.

* Acceptance

- No codec names an ORE Studio page by a path built into compass:
  =trade_type_coverage=, =ore_output_catalogue=, =rule_identifiers=,
  =registry_exceptions= and =route_inventory= read the page from an option.
- A renamed page is still found, and a unit that found it runs again when
  it moves; Catch2 tests fail on the old code.
- An option that is empty, or names an ID no document has, is reported as
  =<codec>/unreadable= on =.compass.org=, and nothing is written.
- On a copy of ORE Studio main with the options set, compass gives the same
  findings and the same diff as before, and still generates the coverage
  note after the note is renamed.

* Plan

- =ops::page_of= in =compass.codec= returns the document whose :ID: an
  option names, through =corpus_view::find_id=. The lookup is an ID input
  whose recorded answer is the page's path, so a move changes the answer and
  the unit runs again; opening the document adds a path input on its content.
  The codecs declare =every_document= so the lookup sees the page whatever its
  type, and enumerate nothing, so they gain no other input.
- =route_inventory= takes a path: ORE Studio's page has no :ID:, and the codec
  writes it whole from its check document's Head table, so there is nothing
  to look up.
- =ore_output_catalogue= writes the ID its option names into the page drawer,
  in place of the ID it hard-coded.
- =check_inventory= keeps its =path= option: it is compass's own page and
  already a setting.
