* Goal

A project gives a built-in codec its curated data as org tables in a check
document, with prose that says what each table is for, and compass-ng stops
parsing that data out of the project's Python. On 2026-11-21 eleven codecs
read data out of seventeen ORE Studio Python files
([[id:66EADA53-4D74-4425-8CEA-CF283177C351][the inventory]]): ORE Studio could
not delete those scripts, a harmless refactor of a Python constant could
break a codec or make it read wrong values, and nothing on ORE Studio's side
showed the dependency. This task builds the mechanism, pilots it on
=conventions_coverage=, and makes a codec name every file it cannot read
rather than stop silently.

* Acceptance

- A check document whose =* Definition= drawer holds =:CODEC: <name>= gives
  that codec one table per level-1 heading, named by the heading, and no
  check of its own.
- Editing the prose around the tables runs nothing again; editing a table
  runs its codec again.
- A document that names no codec, a codec that reads no tables, or a codec
  another document already gives data to, fails the command with its path
  and line.
- A codec whose document is missing, or lacks a table or a column it reads,
  reports so, naming the document; a file it reads and cannot find is
  reported by path, not skipped.
- On ORE Studio's main, =conventions_coverage= reading its check document
  reports what it reported reading =propose.py=.

* Plan

- The tables ride the codec's existing configuration. =parse_codec_document=
  compiles the document's tables into text
  (=codec::ops::encode_data_tables=), and =options_of= sets it as the codec's
  =data= option, after the configuration file and before the run. The
  option is part of the codec's configuration hash, so a table edit runs the
  codec again and a prose edit does not.
- One reader for every codec: =codec::ops::tables_for= decodes the option,
  checks each table the codec needs and its columns, and says, for the
  finding, which document to write or what it lacks. Each row keeps its
  line in the document.
- A cell loses the = or ~ that marks it verbatim, and \vert in it is a
  |, which org's tables cannot hold otherwise and the route rules need.
- =conventions_coverage= reads =Index fields= and =Business day
  conventions=; its =propose= option, which only located the TSVs beside
  =propose.py=, becomes =dataset=, their directory. A new rule,
  =unreadable=, reports a missing table or file instead of the silent
  returns it had.
- The ORE Studio document is generated from =propose.py= by a script, so no
  value is retyped.

* Notes

- An older compass-ng stops on a =:CODEC:= document: v0.0.4 reports "the
  definition names no engine" and runs no check. ORE Studio must install a
  compass-ng that reads them before it commits one.
- =compass config= prints the configuration before check documents apply,
  so it shows a codec's =data= option as its empty default.
