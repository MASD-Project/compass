* Goal

The exported HTML site, and any other client, searches the documents through a
Typesense server with typo tolerance, facets and optionally semantic search,
fed from the same index compass search uses.

* Acceptance

- compass exports its search index as Typesense documents with a schema for
  title, heading path, type, tags, state, sprint, body and link, and pushes
  only the documents that changed since the last push.
- The exported HTML site has a search box that queries Typesense and facets
  by type, tags and state.
- A recorded evaluation compares Typesense's results with =compass search= on
  the same queries, including misspelt ones.
- Running Typesense locally and in CI is documented, and compass works
  unchanged when no Typesense server is configured.
