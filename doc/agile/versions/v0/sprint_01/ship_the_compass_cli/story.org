* Goal

The compass executable runs the pipeline on any checkout: it generates codec outputs, prints a diff that writes nothing, reports diagnostics with a check exit status, and collects the store, configured from a file in the repository.

* Acceptance

- compass generate, compass diff, compass check and compass gc run on this repository and on an ORE Studio checkout.
- Which codecs run, and their options, come from a configuration file in the repository, not from flags alone.
- Exit status: 0 when nothing would change or no diagnostic fires, 1 when something would or does, 2 on failure.
- compass.bench no longer hosts the pipeline; it measures it.
- A recipe tells a person how to run each command.
