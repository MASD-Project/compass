* Acceptance

- Enabling, disabling and configuring a codec needs only an edit to the file.

* Plan

- The configuration is an org file at the repository root, =.compass.org=,
  read with compass's own parser. Keywords set the paths: =#+output:= (the
  output root), =#+meta:= (the contract directory). A table under a
  =* Codecs= heading lists one codec per row: name, enabled (=yes= or =no=),
  and options as =key=value= pairs.
- Precedence: the codec's defaults, then the file, then =--set= and the path
  flags on the command line.
- An unknown codec, an unknown option, a malformed row or a missing
  =* Codecs= table is an error naming the file, line and fix, and exits 2.
  A repository without the file runs on the defaults.
- The file is an input of every run: changing it re-runs exactly the codecs
  whose configuration changed, through the configuration hash already in the
  dependency and cache keys.
- This repository gets its own =.compass.org=, and =compass config= prints the
  effective configuration and where each value came from.
