* Acceptance

- compass generate, diff, check and gc run on this repository with the exit statuses of the story.

* Plan

- New application component =compass.cli= with the =compass= executable. Its
  library holds the pipeline host: list the checkout, resolve IDs, load or
  parse objects, build the type registry, run the enabled codecs with
  dependency records and the result cache, then hand the outputs to the sink,
  the diff or the diagnostics report. =compass.bench= keeps its own copy until
  Hand the pipeline to the CLI.
- Commands, each over the current directory's checkout unless =-C <dir>=:
  - =compass generate= (alias =gen=) writes changed outputs and prints a summary.
  - =compass diff= prints the plan as unified diffs and writes nothing.
  - =compass check= prints diagnostics, one per line as
    =path:line:column: rule: message (fix: ...)=.
  - =compass gc= collects the store, with =--dry-run=.
- Exit status: 0 when nothing would change or no diagnostic fires, 1 when
  something would or does, 2 on failure or bad usage.
- Until Configure codecs from the repository, the defaults are the codecs'
  own and the output root is =build/output/compass=; =--meta= defaults to
  =doc/meta=.

* Result

- =compass.cli= holds the pipeline host as a library, one function per
  command returning a result, and the =compass= executable:
  =compass generate= (alias =gen=), =compass diff=, =compass check= and
  =compass gc=, with =-C=, =--meta=, =--out=, =-j= and =--set=.
- The command was named =write= in the plan; the product owner renamed it
  =generate=, since it produces every output, not only code.
- =diff= and =check= exit 1 when something would change or a diagnostic
  fires; =generate= and =gc= exit 0 on success; every command exits 2 on
  failure or bad usage. Diagnostics print as
  =path:line:column: codec/rule: message (fix: ...)=.
- Relative =--meta= and =--out= resolve against the checkout. Untracked org
  files that no ignore rule covers are part of the corpus, so a new document
  is checked before =git add=.
- =diff= writes nothing at all; =check= writes no outputs but keeps the store
  and records warm.
