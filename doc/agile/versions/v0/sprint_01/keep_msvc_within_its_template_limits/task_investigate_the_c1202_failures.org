* Acceptance

- Every C1202 run of the investigation is classed by mechanism, with its unit and the type it stopped on, or marked unreadable with the reason.

* Plan

Fetch the failed jobs' logs, read each C1202's object, header and
instantiation context with a script, class the errors by mechanism, and
for the unity failure of 2026-11-19 rebuild the target's unity units and
count what each includes.

* Result

[[id:8CE6C3BA-F478-4F65-B34E-88FC06255780][Investigation: the C1202 failures]]. Two mechanisms: one reflected type
too large (81 errors, deep contexts, sources compiled alone) and a
unity unit's accumulated context (6 errors, shallow contexts, an entity
reached late). The second's cost model is not a count of bindings; the
next task measures it on MSVC.
