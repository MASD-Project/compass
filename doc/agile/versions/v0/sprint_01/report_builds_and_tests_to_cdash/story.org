* Goal

Every CI build of compass submits its configure, build, test and coverage results to a CDash project, and a failing build is visible there with its log.

* Acceptance

- A CTestConfig.cmake names the compass CDash project, and a ctest -S dashboard script drives configure, build, test and submit, following ORE Studio's CTest.cmake.
- CI submits pull request and main builds to a Continuous track and a scheduled run to a Nightly track.
- A Nightly run on a debug build submits coverage, and one submits a memcheck run.
- The CDash project shows each build's warnings, failed tests and test times.
- A recipe tells a developer how to find their build on CDash and how to submit a local run.
