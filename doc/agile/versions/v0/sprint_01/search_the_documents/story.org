* Goal

An agent or a person runs =compass search <query>= and gets the few pages that
answer it, ranked, in well under a second, with no server to run and no index
to rebuild by hand.

* Acceptance

- =compass search= (alias =find=) answers a query over every document compass
  parses, ranking title, heading path, tags and body as compass.legacy's
  scorer does, with snippets and =line=, =pretty= and =json= output.
- The index is a codec output kept in the store, rebuilt only for documents
  whose content changed; there is no =index --rebuild= step.
- Filters by document type, tags, state and sprint; past-sprint stories and
  tasks are left out unless asked for, as in compass.legacy.
- =--related= lists each hit's neighbours from the ID-link graph lint already
  builds.
- On ORE Studio, a set of recorded queries returns the same top hits as
  compass.legacy or better, judged hit by hit, and each query answers in
  under 200 ms warm.
- compass.legacy's =index=, =search=, =find= and =debug= rows in Retire legacy
  tooling point here.
