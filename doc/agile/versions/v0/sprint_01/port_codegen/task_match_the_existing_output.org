* Acceptance

- Every generated file is byte-identical, and any difference is listed with its cause.

* Plan

- Make codegen a codec in =compass.codec='s runtime. It loads the models,
  builds contexts, renders, and formats through the result cache, with the
  formatter table moved from =compass.bench= into =compass.codegen=. Then
  =compass generate=, =diff= and =check= run it on a checkout configured by
  =.compass.org=.
- Run =compass diff= on the ORE Studio archive and list every difference from
  the checked-in tree with its cause. The format task found 24: 22 from the
  system-tenant shared-read change that was never regenerated, and 2 hand
  edits.
- Measure a cold and a warm =compass generate= on ORE Studio.

* Result

compass generates all of ORE Studio's generated code as a codec.
=compass generate= on a git-initialised copy of the archive writes 26,212
outputs, byte-identical to ores.codegen's own formatted output. A warm run
takes under 3 s and runs no formatter; a cold run takes 23 to 31 s, most of it
clang-format and prettier.

The 24 files that differ from the checked-in tree are all drift in ORE
Studio:

- 22 from the system-tenant shared-read change, never regenerated:
  =tenor_convention_resolution_repository.cpp=, and for each of the 7 script
  entities the =*_create.sql=, =eventing/*_event.hpp= and
  =repository/*_repository.cpp=.
- 2 hand edits: =ores.marketdata.service/config/options.hpp= (== 0=
  initialisers) and =ores.ore/core/tests/CMakeLists.txt= (=pugixml=).

Of the 26,547 tracked files that carry ORE's "regenerate" marker, 341 are not
codegen outputs: 202 =component_files.cmake= from a separate script, 49
template sources, 42 fpml populate files from a removed parser, 34 PlantUML
schema files, 12 documents that quote the marker, and 2 orphans
(=curve_volatility_parametric_smile{,_parameter}_generator.hpp=) that ORE
should delete.

Decisions to revisit:

- ORE Studio has no =.compass.org= yet, so neither =compass= nor
  =compass-bench render= runs on the real checkout until one is added there.
- The warm run is limited by SHA-1 over the 185 MB dependency record (533
  ms). The record and the result object each hold every output's bytes.
- An empty =year= means the current year, as in ores.codegen, but a change of
  year does not invalidate the cached unit.
- A model that fails to load, or a missing formatter, throws and exits 2,
  because a codec that emits files cannot report diagnostics.
- Formatted results are named by no record, so gc keeps them only for its
  grace period.
- Corpus units share one manifest of at most 8 input sets.
