* Acceptance

- The tangled templates are identical to the ones Emacs produces.

* Plan

- Tangling is a codec over the org tables compass already holds: no Emacs.
  The product owner's rule is that tangles stay simple concatenations.
- In ORE Studio's 226 template sources, 185 blocks carry =:tangle=; none uses
  =:noweb=, =:padline=, =:comments=, =:mkdirp= or =:shebang=, and no file sets
  header arguments by =#+PROPERTY=. One file contains a =<<...>>= pattern,
  which without =:noweb yes= stays literal text.
- So a tangle codec takes each source block with =:tangle <path>= (=no= and
  absent mean skip), concatenates the bodies in document order per target
  path, and copies the three Emacs defaults that change bytes: a blank line
  between blocks tangled to the same file (=:padline yes=), the leading comma
  removed from escaped lines (=,*=, =,#+=), and the path resolved against the
  org file's directory.
- A header argument the codec does not implement makes it emit a diagnostic
  for that block rather than guess, so a template that needs more than
  concatenation is caught, not silently mistangled.
- The oracle is the =.mustache= files Emacs tangled, as committed in ORE
  Studio: every tangled file must be byte-identical. Diff mode then replaces
  the =template-drift= check.

* Result

- Two codecs in =compass.codec=, off by default: =tangle= writes the files and
  =tangle_check= reports blocks it will not tangle. Tangling needs only the org
  tables, so it is not codegen-specific.
- All 171 targets of ORE Studio's template sources are byte-identical to the
  files Emacs tangled, so codegen no longer needs Emacs.
- The byte rules, each taken from Org 9.7's source and confirmed against
  =emacs -Q=: comma unescaping (=,,#+= becomes =,#+=), one trailing newline
  dropped, common indentation removed with tabs counted to the next multiple
  of 8, =org-trim= at both ends, and a newline after each body with one padline
  before every block but the first.
- Blocks under =COMMENT= or =ARCHIVE= headings are skipped, as Emacs does. Any
  other header argument, =#+header:= line or inherited =header-args= is a
  diagnostic, not a guess.
- This repository enables both codecs. =tangle_check= reports the three hook
  scripts in =claude_code_settings.org= that use =:shebang=; supporting it
  (a first line and an executable mode) is a small follow-up if wanted.
- Five committed ORE Studio templates have no source that tangles them; they
  are stale files for ORE Studio to remove.
