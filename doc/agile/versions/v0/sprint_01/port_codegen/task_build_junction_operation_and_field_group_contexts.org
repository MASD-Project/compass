* Acceptance

- All junction (1,124), operation (444) and field group (115) outputs, the 4 registry outputs and the 2 shell aggregators render byte-identical to ores.codegen's raw renders.

* Plan

- Start from the entity task's state: 24,483 of 26,212 renders identical,
  1,727 outputs with no context, and 2 =.shell_aggregator= outputs that
  differ. Those 2 move here, because they aggregate across models as these
  outputs do.
- Use the same oracle and differential (=codegen_render_diff.py
  --every-path=): match each output's context first, then its render.
- Port the junction, operation and field group branches of
  =generate_from_model= into =compass.codegen=, reusing the entity steps and
  the run-wide =entity_registry= where the Python shares code with the
  entity path.
- Classify the 1,727 missing outputs by archetype first, and work in order of
  count.
