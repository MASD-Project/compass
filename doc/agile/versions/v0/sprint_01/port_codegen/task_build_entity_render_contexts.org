* Acceptance

- All 23,805 entity outputs render byte-identical to ores.codegen's raw renders, from contexts compass builds.

* Plan

- The oracle is the one the render task built: =codegen_render_dump.py=
  captures each output's raw text and the context it was rendered from.
  Compare contexts first, then renders: a context that matches renders
  identically, since the engine is exact.
- Port =generate_from_model='s entity enrichment into =compass.codegen= as
  pure functions from =compass.model= values to context values, one step at a
  time in the order the Python applies them, each checked against the oracle's
  contexts before the next.
- Work in order of output count per archetype, so each step moves the most
  outputs to identical.
- Record each remaining difference class with its count when the identical
  rate stops improving cheaply.

* Result

compass builds the context of every entity output, and 23,803 of the 23,805
render byte-identical to ores.codegen. The enrichment is ported step by step
from =generate_from_model= (core.py 4113-6864) into =compass.codegen=, with
Catch2 tests built from the oracle's values.

Left open, moved to [[id:03E4FA2A-CBA9-4D70-BCCC-73D02218A768][Build junction, operation and field group contexts]]:

- =.shell_aggregator= (2 outputs, such as =trading_commands.hpp=): the Python
  scans the model directory for models with the shell command facet and reads
  their component overviews. It is an aggregate across models, like the
  outputs of that task.
- The 1,727 missing renders are outputs compass builds no context for; none is
  an entity output.

Decisions to revisit:

- Context build costs 1.30 s, of which deep copies of the context tree are
  61% of instructions (callgrind): the entity copied into =domain_entity= and
  about 1,000 per-template variants. Sharing nodes through an overlay, and
  looking members up by interned key, are the fixes; both change the builder
  or the renderer. Tracked under Cache formatted output's speed work.
- =compass-bench= reads convention families from a hardcoded
  =projects/ores.refdata/modeling/=, not from the component catalogue.
- =compass.codegen= links =compass.store= privately for SHA-1 (uuid5 recipe
  ids).
- Python's =ValueError= checks are ported only where they guard a value; none
  fires on ORE Studio.
