* Result

All 844 ORE Studio models load identically to ores.codegen, and every one of
the 26,212 outputs ores.codegen produces renders byte-identical from contexts
compass builds.

- The trade type catalogue loader ports org_loader.py 7221-7775 into
  =compass.model/src/ops/trade_type_catalogue.cpp=. =load_model= gains a
  =document_lister= so the loader can scan the checkout's documents.
- The family loader now derives the family's protocol as
  =load_org_family_model= does, reading the central entity through a new
  =entity_document_model=. The codegen copies of that derivation are deleted.
- =trade_type_catalogue_context= ports =_batch_shape_includes=.

Decisions to revisit:

- =_require_family_part= is still checked only in codegen's service view, not
  in the family loader.
- =compass-bench= reads trade type routes with its own parse, which duplicates
  the loader's =routes=.
- The trade type loader re-parses each entity document it reads for columns,
  with no cache; model load rose from 64 to 82 ms.
