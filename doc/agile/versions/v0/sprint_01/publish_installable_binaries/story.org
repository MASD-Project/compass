* Goal

A person or a CI job installs a named compass release with one command, without a compiler, a vcpkg tree or a checkout of this repository.

* Acceptance

- CI builds and tests compass the way ORE Studio does: a CTest dashboard script, continuous Linux builds, and nightly Linux, macOS and Windows builds.
- Every CI build submits its configure, build and test results to a compass project on CDash.
- CPack produces a package for each of Linux, macOS and Windows, and a version tag attaches them to the GitHub release.
- A version tag produces a GitHub release with a binary archive per supported platform, its compass.manifest, and a SHA-256 checksum.
- The release binary depends only on the system C and C++ runtimes, proved by running it in a clean container of the oldest supported distribution.
- An install script downloads a named release, verifies its checksum, installs it under ~/.local/opt/compass and links ~/.local/bin, refusing a checksum mismatch.
- compass --version on an installed release names the tag, the commit and dirty: no.
- A pinned version file lets a consumer such as ORE Studio state which release it needs, and the install script reads it.
