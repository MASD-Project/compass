* Acceptance

- A release carries, for each platform, an archive the install script can
  download (a =.tar.gz= on Linux and macOS, a =.zip= on Windows), its
  installer, and a =.sha256= beside each file.
- Each archive holds =bin/compass= and =bin/compass.manifest=.
- =compass --version= of a tagged build names its tag.
