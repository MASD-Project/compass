* Acceptance

- CTest.cmake, CTestConfig.cmake, CTestSite.cmake and CTestCustom.cmake follow ORE Studio's, submitting to a compass project on my.cdash.org.
- CPack builds a Linux, a macOS and a Windows package as ORE Studio's does.
- Workflows mirror ORE Studio's continuous-linux, nightly-linux, nightly-macos, nightly-windows and site-cdash, and a tag attaches the packages to its release.
- Each departure from ORE Studio is listed with its reason.
