* Notes

- Ubuntu 24.04 LTS is the floor because it is the oldest maintained LTS
  whose glibc covers the newest symbol the binary needs. The CI image is
  Ubuntu 26.04 with GCC 16's libstdc++, which needs GLIBCXX_3.4.36, so the
  binary links libstdc++ and libgcc in. Supporting an older distribution
  would mean building on an older image.
