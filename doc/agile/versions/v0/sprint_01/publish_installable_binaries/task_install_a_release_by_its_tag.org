* Acceptance

- =install_compass.sh --release <tag>= downloads the archive of this
  machine's system and processor and its checksum, refuses a mismatch,
  and installs it as a built tree is installed.
- =--pin <file>= installs the release a consumer's =release:= line names.
- A release that does not exist, and a pin with no =release:= line, fail
  and install nothing.
