* Acceptance

- Every Catch2 suite registers its test cases with Catch2's
  =catch_discover_tests=, prefixed by the suite's name, keeping the Windows
  =~[posix]= filter.
- A Continuous Linux build on CDash lists the individual test cases.
- The cost is measured: local =ctest= time before and after, and the valgrind
  debug nightly's test time.
