* Goal

A reader of the compass readme on GitHub sees, without opening the Actions
tab, whether each CI workflow is green or red, where the CDash dashboard is,
which release is the latest and how active the project is. The readme does
this the way ORE Studio's readme does.

* Acceptance

- readme.org opens with a =badge-wrapper= block in ORE Studio's form: one
  =#+html:= line per badge, each an image inside a link to what it reports.
- A GitHub Actions status badge for each workflow: Continuous Linux, Nightly
  Linux, Nightly MacOS, Nightly Windows and CI Image. Each links to its
  workflow's runs, so a red badge goes to the failing run in one click.
- A CDash badge links to =https://my.cdash.org/index.php?project=Compass=.
- The repository badges ORE Studio shows, pointed at =MASD-Project/compass=:
  maintenance, licence (GPLv3), C++ standard and compiler versions, sprint,
  GNU Emacs, commit activity, status, last commit, open and closed issues,
  open and closed PRs, contributors, releases and downloads.
- No badge is copied that names an ORE Studio resource compass does not have,
  such as the Doxygen site, the website or the Discord server. Each one left
  out is listed under Notes with its reason.
- Each badge renders on the GitHub page of the merged readme, and each link
  opens the page it names. A badge for a release, or for a workflow that has
  not run yet, can show "none" until the first release or run.
- =compass.sh lint= and =compass check= pass on the change.

Copy lines 16 to 46 of ORE Studio's =readme.org= and replace =OreStudio/OreStudio=

* Notes

Versions come from the repository: C++23 from =CMakePresets.json=, clang 21
and GCC 16 from =build/docker/ci/versions.env=, MSVC from the
=windows-latest= runner, so its badge says =latest= rather than a year. The
sprint badge links to =sprint.org= on GitHub, since compass has no website.

Left out of ORE Studio's block:

- Doxygen, Website and Discord: compass has no Doxygen site, website or
  Discord server.
- Contributing: compass has no =CONTRIBUTING.md=.
- PRs since and Commits since the last release: both name a release tag, and
  compass has none yet. Add them with the first release.

Every badge image and link returned HTTP 200 except gnu.org, which timed out
from the development machine; ORE Studio links to the same page.
