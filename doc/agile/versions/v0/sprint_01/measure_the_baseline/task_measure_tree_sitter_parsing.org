* Acceptance

- Parse time for all C++ and all SQL is known on 8 cores, with a per-file ERROR count; a fallback is named if C++ exceeds 5 seconds.

* Plan

- vcpkg overlay ports under =build/cmake/overlays/common=, as in ORE Studio:
  =tree-sitter-cpp= 0.23.4 from its repository and =tree-sitter-sql= 0.3.13
  from its release tarball. Both ship the generated =parser.c= and
  =scanner.c=, so the ports compile them directly, without the tree-sitter CLI
  or Node.js. =tree-sitter= itself comes from vcpkg.
- Add a =parse= stage to =compass-bench=: parse every C and C++ file and every
  SQL file in the file table with tree-sitter, one parser per thread, over the
  mapped bytes.
- Per file, record the parse time and the number of =ERROR= and =MISSING=
  nodes. Trees are deleted after counting; nothing is kept.
- Report per language: files, bytes, median, min and max wall time over the
  repetitions, MB/s, files with errors, total error nodes, and the ten worst
  files by error count and by parse time.
- If parsing all ORE Studio C++ takes more than 5 seconds on 8 threads, the
  result names a fallback: a lighter scanner for the facts the metrics need.
