A frozen benchmark harness and two baselines: what ORE Studio's codegen and gates cost today on an idle machine, and how fast the whole ORE Studio tree can be read and parsed.

* Acceptance

- The current codegen and gate timings are re-measured on an idle machine, one run at a time, as the median of at least five samples.
- One command reports, per stage, the wall time and bytes processed for reading, include scanning, and tree-sitter parsing of all ORE Studio C++ and SQL.
- The tree-sitter ERROR node count per file is recorded for C++ and SQL, so grammar coverage is known before anything depends on it.
- The numbers are recorded in the story's investigation with the command and the ORE Studio commit that produced them.
