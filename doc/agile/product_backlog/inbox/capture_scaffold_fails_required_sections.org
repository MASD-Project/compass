* Note

=compass add capture= writes =* What= and =* Why= sections. The capture
contract (=doc/meta/document_type_capture.org=) accepts those as synonyms for
=* Note=, but =required_sections= reads only the list's first form and reports
=missing_section= on every new capture. ORE Studio has the codec off, so only
compass sees it.

* Actions

- Teach required_sections the contract's synonyms, or make the scaffold write =* Note=.
