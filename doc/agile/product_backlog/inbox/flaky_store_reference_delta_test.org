* Note

compass.store.tests' "objects stored as reference deltas read as git prints
them" failed once during a CTest dashboard run of the CI port: =kinds[1] == 0=
failed with 55 == 0, so the synthetic repository the test builds had packed
offset deltas where it expects none. Run alone it passed six times out of six.
The guess is that git's packing depends on load or timing under parallel ctest;
the test should force the delta kind it means to read rather than rely on git's
choice.

* Actions

- Reproduce by running the suite under =ctest -j= repeatedly.
- Pin the pack's delta kind in the test fixture.
