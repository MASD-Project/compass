Each step references a recipe or skill by id-link.

* Goal

Add a new domain entity (e.g. currency, counterparty, trade) with support across all layers: domain type, SQL schema, repository, service, CLI commands, HTTP endpoints, and unit tests.

* Preconditions

- Entity name and fields are defined.
- Current sprint has a story for this entity.
- Build environment is configured per [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][development environment setup]].

* Steps

In execution order:

1. /Create the domain type./ Use [[id:B1450696-8C51-4CC5-8910-84912A411AB6][Domain Type Creator]] skill to generate the C++ domain model, serialisation, and JSON I/O.

2. /Create the SQL schema./ Use [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][SQL entity schema patterns]] and [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][How do I create entity schema?]] to add the table, CRUD functions, and grants.

3. /Create the repository./ Follow [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][Entity lifecycle]] to scaffold the C++ repository class.

4. /Wire the service layer./ Add NATS handlers and service methods following the protocol conventions in [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][Protocol Reference]].

5. /Add shell commands./ Follow [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][Shell facet]] and [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][How do I create entity commands?]] (ores.shell).

6. /Add HTTP endpoints./ Follow [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][Shell entity patterns]] and [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][How do I create entity endpoints?]].

7. /Write unit tests./ Follow [[id:4D3C2B1A-9E8F-4A7B-6C5D-3E2F1A0B9C8D][Unit test conventions]] and [[id:CB56337E-4839-4048-B5A7-C481812CE3D0][Unit Test Writer]] skill.

8. /Commit and PR./ Follow [[id:2EA7FF1B-CC23-4275-9ADA-8C43103E3103][Work a task through to merged PR]] for the full PR lifecycle.

* Postconditions

- Entity is functional across all layers.
- All tests pass.
- RLS policies (tenant isolation; party isolation if =party_id= present) are in
  place and registered in =rls/rls_create.sql=.
- Detail dialog calls =promptChangeReason()= before save (Create/Amend) and
  before delete; =change_reason_code= and =change_commentary= are set on the
  domain entity before the request is sent.
- Notify trigger uses =ores_utility_iso8601_timestamp_fn(change_timestamp)= for
  the timestamp field in =pg_notify= payloads.
- PR is open with the entity changes.
