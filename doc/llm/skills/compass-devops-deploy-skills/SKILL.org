* When to use this skill

Skill sources changed and the deployed bundle is stale (compass bearings warns): rebuild and prune.

* How to use this skill


1. /Deploy after every skill edit/. The harness reads the deployed bundle,
   not the org sources, so an unbuilt edit changes nothing for any session.
   The deploy prunes the bundle after it writes, so a renamed or retired
   skill does not linger under its old name.

2. /Tell the user to run =/reload-skills=/. A running session holds the
   bundle it started with, so until it reloads, the edit is live on disk
   and invisible to the very session that made it.
