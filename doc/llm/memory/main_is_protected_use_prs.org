main is protected on GitHub: no direct pushes, no force pushes, no deletion, and the rule applies to admins. Every change lands through a pull request from a feature branch.

*Why:* The product owner asked on 2026-10-27 to protect main and use PRs from then on.

*How to apply:* Start each unit of work on a feature/ branch, push it, and open a PR with gh pr create. A PR needs no approving review, but every review conversation must be resolved before it merges.
