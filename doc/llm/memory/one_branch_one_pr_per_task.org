#+title: One branch and one PR per task, merged before the next
#+description: Work one task at a time on a single feature branch off main, raise its PR, review it, merge it, then start the next task. Never stack branches.
#+type: memory
#+memory_subtype: feedback
#+level: cross
#+filetags: :memory:feedback:
#+created: 2026-11-16
#+updated: 2026-11-16

Work one task at a time on a single feature branch cut from an up-to-date main. When the task is done, raise its PR, review it, merge it, sync main, and only then start the next task. Never base a branch on another unmerged branch.

*Why:* Stacked branches had to be rebased one by one when an older PR merged first, and every rebase replayed conflicts in the same status tables. The user asked on 2026-11-16 to stop stacking: one feature branch, one PR per task, merge, then proceed.

*How to apply:* Before starting a task, switch to main and pull. Cut the task's branch from main. Do not start the next task until the current PR is merged. A small fix found mid-task that is not part of the task becomes its own task after the merge.
Pushing, raising, reviewing and merging the task's PR are part of finishing
the task, so this memory takes precedence over
